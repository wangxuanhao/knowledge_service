# **到店综合业务商户违规处理规范实施细则**

## **第一章****总则**
**第一条**根据《到店综合业务商户违规处理规范》（以下简称《规范》）规定，制定本实施细则。

## **第二章****违规行为类型**
**第二条**《规范》第四章第十二条【发布信息】违规，第一项中的【发布错误信息】主要包括：

### （一）商户发布的产品/服务的标题与具体内容描述不相匹配的；
（二）商户发布非预付的产品/服务，但涉及到店支付、预付、到店补余额/补差价、咨询单等内容的，属于行业通用做法的除外；
（三）商户发布的产品/服务的有效期或者除外日期错误或前后不一致的；
（四）商户发布的产品/服务的预约信息错误、重复出现或前后不一致的；

### （五）商户发布的产品/服务消费门槛设置错误、不合理的；
（六）商户发布与产品/服务无关的信息，如涉及线下的优惠活动等；
（七）商户在标题、产品/服务介绍中进行无合理依据的自我标榜，如“人气推荐”、“五星推荐”等；
（八）商户在标题、产品/服务介绍中发布涉及性能、效果断言或保障性承诺等内容；

### （九）其他被认定为发布错误信息的。
**第三条**《规范》第四章第十二条【发布信息】违规，第二项中的【服务发布不规范】主要包括：
（一）商户在标题、产品/服务介绍中发布单独外国文字、拼音、繁体字等内容；
（二）商户在标题、产品/服务介绍中发布语义存在歧义或描述不清等内容；
（三）商户在标题、产品/服务介绍中发布带有未经授权的品牌、微信、公众号、QQ、网址、水印、APP、二维码或截图等内容；
（四）商户在标题、产品/服务介绍中使用违反或疑似违反广告的内容，如使用绝对化用语或通过语义判断为绝对化描述词语或非医疗品类使用医疗用语；

### （五）其他被认定为服务发布不规范的。
**第四条**《规范》第四章第十五条【交易和提供服务保障】违规，第九项中的【严重违规行为】主要包括：
（一）商户或其员工非法收集、使用，泄露、出售消费者个人信息的行为；
（二）商户或其员工对消费者进行骚扰、言语辱骂、诽谤、恐吓威胁的行为；

### （三）商户或其员工盗取、诈骗消费者财产的行为；
（四）商户或其员工在提供产品/服务过程中造成消费者人身安全的行为；

### （五）商户或其员工对消费者进行性骚扰、性侵、投毒的行为；

### （六）商户或其员工在提供产品/服务过程中虐待动物的行为；

### （七）其他被认定为严重违规的行为。

## **第三章****违规处理**
**第五条**【发布错误信息】
商户存在本实施细则第二条行为时，美团将根据如下规则对商户进行处罚：

| **累计违规行为次数** | **一次警告** | **二次警告：再次违规将限制产品****/****服务发布权限** | **限制产品****/****服务发布权限** | **处罚期** |
|---|---|---|---|---|
| 1 | √ |   |   | / |
| 2 | √ | √ |   | / |
| 3次及以上 |   |   | √ | 24小时 |

**第六条**【服务发布不规范】
商户存在本实施细则第四条行为时，美团将根据如下规则对商户进行处罚：

| **累计违规行为次数** | **一次警告** | **二次警告：再次违规将限制产品****/****服务发布权限** | **限制产品****/****服务发布权限** | **处罚期** |
|---|---|---|---|---|
| 1 | √ |   |   | / |
| 2 | √ | √ |   | / |
| 3次及以上 |   |   | √ | 24小时 |

**第七条**【严重违规】

### （一）违规程度判定
商户存在《规范》第四章第十五条【交易和提供服务保障】违规，第九项【严重违规行为】的，美团将从用户损失程度和商户配合度两个维度判定商户处罚程度，具体如下：

| **商户处罚程度判定（轻、中、重）** | **商户配合程度** |  |  |  |
|---|---|---|---|---|
|   | 配合满足用户诉求 | 配合平台/用户取证 | 不配合 |  |
| **用户损失程度** | 轻微 | 轻 | 轻 | 中 |
|   | 一般 | 轻 | 中 | 重 |
|   | 严重 | 中 | 中 | 重 |

（二）美团有权根据商户的处罚程度，对于商户处以不同的处罚措施，具体如下：

| **商户处罚程度** | **处罚措施** |
|---|---|
| 轻 | 警告、限制账户部分权限（如：限制营销权限） |
| 中 | 限制账户部分权限（如：限制上单/修改权限、门店清星级、门店评价隐藏、搜索黑名单） |
| 重 | 限制资金账户权限、下线店铺、终止合作关系 |


## **第四章****附则**
**第八条**本实施细则自2021年6月4日发布，公示期为七天，公示期满后正式生效。美团将不定期地修改和完善本实施细则，修改完善后的实施细则将在商家中心的规则中心进行公示并通过相关渠道通知商户，请商户及时关注和阅读。
