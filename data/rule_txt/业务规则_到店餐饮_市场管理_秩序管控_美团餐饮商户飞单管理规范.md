# 美团餐饮商户飞单管理规范

### 一、概述
1.1 目的
为保障平台商户与用户的合法权益，维护平台正常经营秩序，实现商户规范化运营，根据国家法律法规、商户与平台的合作协议（包括但不限于《商户入驻服务合同》等）以及平台规则等，特制定此规范。
1.2 适用范围
本规范适用于美团平台餐饮行业所有合作商户（以下简称为“商户”），以及商户与美团平台合作的包括但不限于团购、代金券、自提、配送、预定、预付等现有及未来可能上线的产品（以下简称“合作产品”）。

### 二、飞单违规场景及判定
2.1 定义
“飞单”是指在用户已购买或有明确意向购买美团平台合作产品的情况下，商户以明示或暗示等方式引导或诱导用户放弃通过美团平台进行消费的行为。商户飞单行为可分为成单前飞单和成单后飞单。成单前飞单，指商户在用户购买美团平台合作产品前，如在选品、咨询等有购买意向阶段，通过编辑团单信息、商户页面信息、直播间信息等任何方式引导或诱导用户转至其他非美团渠道消费；成单后飞单，指商户在用户购买平台合作产品后，引导或诱导用户放弃美团订单而转至其他非美团渠道支付消费款项。
2.2 违规场景
具体飞单违规场景包括但不限于：

| 分类 | 违规场景 |
|---|---|
| 成单前飞单 | （1）在消费者咨询或线上选购时，商户引导或诱导消费者不使用平台的合作产品，改用现金、刷卡或其他支付方式消费款项； （2）商户通过团单信息、商户信息、直播间信息等渠道，引导或诱导消费者不使用平台的合作产品，改用现金、刷卡、或其他支付方式消费款项； （3）其他引导或诱导消费者放弃通过美团进行消费的行为。 |
| 成单后飞单 | （4）引导或诱导消费者退掉美团合作产品订单，改用现金/刷卡/支付宝/微信等线下支付方式或引导去其他平台下单。 （5）引导或诱导消费者使用店内会员优惠方式替代通过美团进行消费支付。 （6）提供其他更为优惠的方案诱导消费者通过非美团方式进行消费支付。 （7）其他引导或诱导平台消费者改用其他方式支付消费款项的行为。 |

2.3 飞单行为核查及判定
2.3.1 商户应当遵守平台规则，诚信经营店铺。平台在收到举报、投诉或获取可信的线索、证据的情况下，有权对商家飞单情况进行核查。
2.3.2 平台有权通过数据排查，从核销情况、退款情况、售后申请、消费者行为等维度对异常的交易数据进行核查，并判断是否属于飞单行为。如商家被认定存在异常行为，除非商家能够做出合理解释和提供相应证据且被平台认定为合理的，否则将被判定为飞单。

### 三、违规处理和申诉
3.1 处理措施
**平台有权视商户飞单行为的严重程度和发生频次，采取如下违规处理措施：**

### **【行为纠正】下架商品、删除商品或信息**

### **【行为处罚】**

| 时间范围 | 累计违规次数 | 警告 | 搜索排序降权 | ROS扣分 | 取消上榜资格 | 产品隐藏且不可购买 | 违规团单下线 | 处罚期 |
|---|---|---|---|---|---|---|---|---|
| 近180天（以当次违规通知日起计算） | 1次 | √ | √ |   |   |   |   | 3天 |
|   | 2次 | √ | √ | √ | √ |   | √ | 7天（违规团单下线不适用该处罚期） |
|   | 3次及以上 | √ | √ | √ | √ | √ | √ | 15天（违规团单下线不适用该处罚期） |

3.2 特别说明
（1）在6个月统计周期内，商户飞单违规次数达到3次时，再次违规则直接按累计3次的标准实施处罚，例如：商户在60天内违规次数达第4次，则直接在15天处罚期基础上再增加15天，以此类推。
（2）平台处理措施不影响商户履约义务，商户应继续完成已售订单的履约，不得以团购下线等为由拒绝接待用户。
（3）商户门店内任意某一项目存在的飞单问题，一经核实，均以门店维度进行处罚，且处罚项针对商户的美团平台门店和/或大众点评平台门店。
（4）商户违规行为若涉及平台补贴或者优惠政策的，平台有权执行冻结打款措施，并扣除优惠补贴费用。
（5）平台可根据商户违规程度在上述处罚措施的基础上，增加上单/修改权限关闭、产品隐藏且不可购买、违规团单下线、追究赔偿、隐藏商户门店或终止与商户的所有合作等措施并相应延长处罚期。
（6）平台可在官方网站、商户中心、微信公众号等渠道选择对商户违规行为和处罚措施进行公示。
3.3 申诉规则
（1）平台做出处罚决定后将通知商户，对于处罚决定有异议的，商户应在通知之日起3个自然日内提起申诉（申诉渠道：https://ecom.meituan.com/diting/b/m/appeal/list)，商户在申诉时应提供能证明其申诉理由的证据材料。商户也可通过商服热线10105557或业务经理向平台进行反馈，并提供相应证明材料，同时进行整改以符合本规范。
（2）美团将对商户的申诉予以审查，若申诉理由成立，则不予处罚；若申诉理由不成立，则按照处罚决定予以处罚；若商户未在申诉期内申诉的，视为商户无异议，将按照处罚决定予以处罚。
（3）为了保证申诉的有效性，提高申诉成功率，商户申诉时需按照平台的要求提供完整、真实、有效的证明材料，如商户提供虚假证明材料的，即视为申诉不成立。商户恶意申诉，或者提供虚假证据，将依据情节予以加倍处罚。

### 四、附则
4.1 规范变更
平台有权对本规范内容进行修改、补充或更新，并在该规范生效前通过平台页面/商户中心等渠道予以公告，上述公告一经发布即视为已经单独通知到每一家使用平台服务的商户；若商户在本规范内容修改、补充或更新公告后继续使用平台提供的服务，即视为商户同意遵守修改、补充或更新的规范。
4.2 规范效力
本规范作为商户与平台所签署协议的附件，与协议具有相同法律效力。商户违反本规范的，按照本规范、双方协议及其他管理规范进行处罚。
4.3 规范溯及力
发生在本规范生效之日前的行为，适用当时的规范进行处理；发生在本规范生效之日后的，适用本规范。
4.4 生效
4.4.1本办法于2018年6月25日发布，并于2018年7月2日正式执行。本规范最新修订日期为2025年5月19日，自发布之日起7日后生效。
4.4.2美团有权根据国家法律法规的变化以及实际业务运营的需要随时调整本办法相关内容，在按照程序进行修改后，将通过平台页面/商户中心等方式向商户进行公示。
