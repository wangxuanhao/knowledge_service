# 大众点评点星平台达人履约分管理规则
规则版本：【2.1】
制定日期：2025年2月
更新日期：2025年8月26日
生效日期：2025年9月03日

### **一、概述**
鉴于达人与商家就探店写笔记等事宜达成一致合作意见。为了更好的提高达人履约服务质量，切实保障商家利益的同时激励达人高质量完成商单履约制定本《大众点评点星平台达人履约分管理规则》。

### **二、定义以及适用范围**
**（一）履约分：**履约分是大众点评点星推出的衡量达人“履约行为和内容违规行为”的核心指标，覆盖平台履约与笔记内容创作等多个场景。以分数量化的形式展现达人在平台接单的质量，提升能力评估的公平性，助力内容创作的规范化提升。

### **（二）规则适用范围**
适用于所有已入驻点星且可接单的达人以及所有商单类型，包括但不限于应用在全民合作、分成合作、无忧合作、定制合作、招募合作等点星所有产品模式下的商单。

### **三、履约分考核标准**
每个达人信用分初始分为100分，上限100分、下限0分

### **（一）加分规则**
加分分为守约加分和任务加分两种类型。每个自然周内就加分上限为10分，超出10分按10分计算。
1.守约加分：自然周内，达人发布商单笔记≥1篇且无任何履约违规行为，加5分。每个自然周产生的加分行为，将在周一10:00生效。
2.任务加分：自然周内，阅读完整的点星诚信规则，加5分。加分实时生效。

### **扣分规则**
1.扣分主要从履约违规和内容为违规两方面考核。
2.扣分生效节点，将根据履约违规类型进行实时扣分或参考达人申诉行为和结果判定后生效。
3.自然周内，同一种违规类型违反多次，分别扣分。

| **考核方向** | **违规类型** | **违规行为示例** | **扣分标准** |
|---|---|---|---|
| 履约违规 | 超时未履约 | 在履约的任意环节没有及时响应，导致任务被取消，包括但不限于： 接单后，没有及时到店打卡 接单后，没有在笔记发布周期内发布笔记 笔记被驳回后，没有及时修改笔记 | 出现1次扣5分 |
|   | 不当竞争 | 通过不正当的方式操控账号参与商单任务，包括但不限于： 借用或盗用他人账号，参与商单报名及履约 一人养多号，损害合作商单的公平性、导致不正当竞争 | 出现1次扣5分 |
|   | 虚假探店 | 违反平台倡导真实探店的原则，在未实际到店的情况下创作笔记，包括但不限于： 临时修改账号定位，进行作弊 非本人真实到店，账号授权给本人以外的用户，完成笔记发布 | 出现1次扣10分 |
|   | 非诚信履约 | 接受商家接待后，最终未发布笔记，导致门店资损等行为，包括但不限于： 某次到店后，享用商家提供的免费餐食或服务，离店后忘记发布笔记，导致任务取消 习惯性以接商单任务为名，白嫖商家接待资源，造成商家资损 携带跟履约不相关的亲友到店吃喝，造成商家接待资源损失 | 出现1次扣5分 |
|   | 消极履约 | 不熟悉任务流程且不主动推进履约、到店后懈于配合商家要求，包括但不限于： 未充分了解任务流程，到店后不知道该干嘛 需要机构或商家频繁催促才开展下一步履约动作，如迟迟不到店、到店后不进行素材拍摄等 无视或刻意不配合商家要求，笔记创作方向与商家要求相悖或不参考修改意见修改笔记等 | 出现1次扣5分 |
|   | 负向情感创作 | 因达人自身无理要求，导致商家难以配合后，进行负向创作，包括但不限于 要求商家提供超额接待资源/在门店接待资源不足的情况下强行探店等，导致商家无法接待，达人刻意给门店写差评或负向笔记，造成门店声誉受损 | 出现1次扣10分 |
| 内容违规 | 虚假创作 | 对所推广的门店或团购进行虚假宣传，包括但不限于： 抄袭、盗用他人原创内容，包括但不限于点评站内外的评价或笔记，发布缺乏实际到店真实体验的“云探店”内容 对分享门店信息或服务项目、购买价格、使用规则、适用范围、履约方式（如：支持配送、外卖等）、功能效果、资质认证等信息进行不实或夸大描述 虚构商品或服务原价 使用绝对化、欺骗性或误导性的语言，文字，图片，计量单位等 以商家品牌、LOGO、科普新闻等方式宣传医疗医美商品 对所分享门店的服务及价格等进行不实或夸大描述 宣传的商品信息或使用规则，与商品详情页不一致等 | 出现1次扣10分 |
|   | 虚假互动 | 操纵自有或其他账号、利用第三方炒作团伙或通过与他人协商等不正当方式获取虚假的笔记曝光、转赞评等互动数据的行为 | 出现1次扣5分 |
|   | 色情低俗 | 内容包含低俗（或易引发低俗联想的）表演、动作、图片、语言等 | 出现1次扣5分 |


### **四、违规申诉**
被扣分后的24小时内，达人可以进行申诉**，超时未申诉将无法再次发起申诉且将视为对于处罚的认可。**

### **五、处罚措施**
80≤履约分≤100，平台将向达人发出警告，给予达人改正的机会，暂时不会发起处罚；履约分<80，将参考下列“处罚措施”对达人进行处罚。

| **履约分** | **无忧合作&定制合作&招募合作** | **全民合作&分成合作** |
|---|---|---|
| 80≤履约分≤100 | / | / |
| 70≤履约分＜80 | 达人广场不出现15天 不可接单15天 | 不可中奖15天 |
| 40≤履约分＜70 | 达人广场不出现30天 不可接单30天 | 不可中奖30天 |
| 0≤履约分＜40 | 达人广场不出现60天 不可接单60天 | 不可中奖60天 |
