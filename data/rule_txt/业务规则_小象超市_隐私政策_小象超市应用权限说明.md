# **小象超市****权限说明**
1、iOS系统权限调用说明

| **设备权限** | **功能说明** | **使用目的** |
|---|---|---|
| 位置 | 获取用户位置信息 | 用于向用户推荐周边的小象超市配送站、使用地图导航功能等 |
| IDFA（iOS14及以上） | 识别用户广告识别符 | 用于保障用户的账号、交易安全及接收个性化广告 |
| 相机 | 调用摄像头拍摄 | 用于扫码、拍照、上传图片/视频 |
| 麦克风 | 调用麦克风录音 | 用于录制视频时通过麦克风获取声音 |
| 照片 | 读取、写入相册 | 用于写入和读取用户相册信息 |

2、Android 系统权限调用说明

| **设备权限** | **功能说明** | **使用目的** |
|---|---|---|
| 位置 | 获取用户位置信息 | 用于向用户推荐周边的小象超市配送站、使用地图导航功能等 |
| 相机 | 调用摄像头拍摄 | 用于扫码、拍照、上传图片/视频 |
| 悬浮窗 | 调用悬浮窗 | 用于用户保持客服消息时提供快捷入口等功能 |
| 存储 | 读取、写入存储 | 用于存储和读取上传用户拍摄的照片和视频，以及实现应用内升级和页面数据缓存等 |

3、HarmonyOS 系统权限调用说明

| **设备权限** | **功能说明** | **使用目的** |
|---|---|---|
| 位置 | 获得用户位置信息 | 用于向用户推荐周边的吃喝玩乐和出行服务、使用地图导航功能等 |
| 后台访问位置 |   |   |
| 电话状态 | 访问电话状态 | 获取设备识别码用于保障用户的账号及交易安全，以及获取设备通话状态 |
| 相机 | 调用摄像头拍摄 | 用于扫码、拍照、上传图片/视频 |
| 蓝牙 | 发现和连接蓝牙设备 | 用于单车的蓝牙开锁、辅助定位等 |
| 存储 | 读取、写入存储 | 用于存储用户拍摄的照片和视频，以及实现应用内升级和页面数据缓存等 |
| 悬浮窗 | 调用悬浮窗 | 用于将直播等内容以悬浮窗的形式在其他页面上显示，用户保持客服消息时提供快捷入口等功能 |
| 日历 | 写入日程信息 | 用于向用于提供预订日程记录和提醒服务 |
