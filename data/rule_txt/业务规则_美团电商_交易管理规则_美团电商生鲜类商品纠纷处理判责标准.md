# 美团电商生鲜类商品纠纷处理判责标准

版本 V6.1
生效日期: 2025年09月07日

## **第一章  概述**
1.1适用范围
本标准适用于美团电商平台生鲜类商品纠纷。生鲜类商品包括但不限于海鲜水产、水果蔬菜、肉禽制品、蛋制品、豆制品、蔬菜、水果、快手菜等。
1.2受理范围
美团电商受理买卖双方在美团电商平台上就生鲜类商品产生的交易争议处理申请，但出现以下情形的，美团电商可不予受理，买卖双方自行协商解决或任意一方自行通过司法机关等途径向相对方主张权利。
1.2.1任何因消费者自身的签收、保管或处置不当导致污染或质量问题的商品；
1.2.2因消费者撕毁或涂改标贴、防伪标记、特殊包装而无法确定来源的商品；
1.2.3基于个人审美、口感、喜好等主观因素为由提出退换货的商品；
1.2.4买卖双方经自行协商达成退款或退货退款协议并履行完毕，一方或双方反悔产生纠纷；
1.2.5买卖双方进行虚假交易或套利套券一经查实的订单；
1.2.6交易做退款处理后，因商家需要取回商品产生争议；
1.2.7除美团电商平台规则规定的情形外，消费者主张交易引发的额外损失或法定赔偿事宜。

## **第二章 生鲜类商品管理规范**
2.1买卖双方行为规范 
2.1.1除质量问题外，生鲜类商品一经售出不支持7天无理由退换货服务，但双方另有约定的，从其约定；
2.1.2商家发货或消费者退货后，收件人应亲自签收商品，收件人委托他人签收商品或承运人已按收件人的指示将商品置于指定地点的，视为收件人本人签收。  
2.2商家行为规范
2.2.1鉴于生鲜类商品的特殊性，针对商品保质期（如保质期限、是否临近保质期等），商家应在商品详情页中如实描述；如消费者主张收到的商品为临期商品，且消费者可提供图片证明商品临期的，商家应对为消费者办理全额退款。 
临期定义

| **保质期** | **临期商品** |
|---|---|
| 365天≤保质期 | 0<剩余保质期≤45天 |
| 180天≤保质期＜365天 | 0<剩余保质期≤30天 |
| 90天≤保质期＜180天 | 0<剩余保质期≤20天 |
| 30天≤保质期＜90天 | 0<剩余保质期≤10天 |
| 15天≤保质期＜30天 | 0<剩余保质期≤5天 |
| 保质期＜15天 | 0<剩余保质期≤4天 |

2.2.2如商品有签收时效等特殊要求，商家需在商详页顶部显著位置和美团电商在线客服工具进行提醒，告知消费者签收标准。
2.2.3如快递员未与消费者确认，直接将包裹放置在自提点、自提柜，导致生鲜食品变质，消费者有权要求商家承担违约责任。
2.2.4如消费者在商家发货后，快递揽收前提出退货申请，商家不可驳回用户售后诉求，需将商品自行召回。
2.2.5若美团电商依据本规范内容先行对消费者进行了赔付或支持了消费者的退货退款申请的，相关费用由商家自行承担。若美团电商先行支付的，美团电商有权自商家待结款项或保证金中予以抵扣。若保证金不足的应当按照《美团电商合作协议》相关规定限期补足。 
2.2.6部分水果考虑运输时长等因素，需在未完全成熟条件下采摘并配送，消费者收到商品时需对商品进行催熟处理后，方可食用。 **商家需在商品详情****页显著****位置展示“需催熟类水果”的催熟方法，并针对催熟时间进行详细说明，** 常见的需催熟类水果有：榴莲、芒果、猕猴桃、菠萝蜜、牛油果、释迦、木瓜等。未作特别说明的，平台介入处理后，将依照普通人的认知水准及日常经验，根据气候、商品类型等因素判断。
催熟方法

| **品类** | **建议催熟方法** | **催熟周期** | **特别提醒** |
|---|---|---|---|
| 木瓜 | 摘掉网套放2-3个苹果或者香蕉，箱子密封放在温度高的地方（20度以上环境）催熟3-7天左右务必每日打开观察，表面有水气需要擦干，如果按着软点就可以食用的，没熟的果子切勿放冰箱，熟了可以放冰箱冷藏，生鲜水果熟透建议尽快食用。 | 收到后3-7天左右，不超过14天 | 木瓜未成熟时不建议放入冰箱，已经成熟的果实容易坏烂，务必及时放入冰箱保存。 |
| 芒果 | 摘掉网套放2-3个苹果或者香蕉，箱子密封放在温度高的地方催熟3-7天左右务必每日打开观察（20℃以上环境），表面有水气需要擦干，如果按着软点就可以食用的，没熟的果子切勿放冰箱，熟了可以放冰箱冷藏，生鲜水果熟透建议尽快食用。有任何疑问都可以询问客服，我们坏果都是包赔的。备注:芒果品类较多无需在意果皮颜色，捏着软了即是熟了。 | 收到后一般3-7左右，不超过14天 | 芒果未成熟时不建议放入冰箱，成熟后方可放入冰箱，以延长保鲜时间。 |
| 猕猴桃 | 收到把泡沫托取出果子放纸箱里，或者把果子取出放塑料袋里，里面放2-3个苹果或者香蕉催熟，放在温度高的地方催熟按着有点软了就可以食用了。催熟中务必每天查看有 水气一定需要擦干按着软点就可以食用了。备注: 查看催熟时切勿按捏果身，可以按压两头查看是否可以食用。 | 收到后5-10天左右，不超过14天，有手感即可食用 | 不建议长时间低温放置，不易催熟且易造成果体变质。 |
| 菠萝蜜 | 箱子里放2-3个苹果或者香蕉，箱子密封放在温度高的地方（20℃以上环境）催熟3-7天左右务必每日打开观察，如果能捏动并且闻着有香味就是熟了。备注:想要成熟快些可以把果子放在太阳下晒晒,注意观察避免熟过头的现象，如果熟了可以把所有果肉剥出放保鲜袋放冰箱冷藏，可放7天左右，果肉切勿沾水。 | 收到后一般3-7左右，不超过14天 |   |
| 榴莲 | 为了快递运输安全给您发出7-8成熟的果子，判断榴莲的熟度，给你支招： 1、取相邻两根刺，用大拇指和食指稍用力捏，如两根刺稍软可以轻松靠拢，达到成熟可食用状态。 2、有裂缝、榴莲散发出果香。 3、榴莲拿起来摇一摇，听着有果肉晃动感，也是成熟的。 4、在凸起部分切个小三角形查看里面果肉熟度！不熟就盖回去继续催熟。 如果榴莲还未完全成熟，请放置在透气干燥温度高的地方，榴莲底部一定要放报纸或者纸皮垫着，切勿直接放地板上，也不要放在冰箱，不然会影响榴莲成熟。 另外，已经裂口的榴莲，要注意及时食用，过熟会影响口感。 | 收到后一般2-5天左右，不超过14天 | 打开后的果实应尽快食用，未食用部分务必放入冰箱冷藏保鲜。 |
| 释迦 | 如果释迦果顶端开裂或表皮变黑，用手轻轻一按即有糖分流出，表示已经成熟即可食用。如果表皮鲜绿，手感较硬就是还没有成熟。 催熟方法：可以和其它水果放在一起催熟。准备几个完全成熟的苹果或其它水果，将它们放在塑料袋中密封起来，并且保持气候温暖，通常一到两天后就会成熟。这种方法是借助了成熟水果散发的乙烯，通过它来对没熟的水果进行催熟，因此这种方法也很通用。另外，需要注意一点：因为释迦果是热带水果，天生怕冻，不能把释迦果放入冰箱里冷藏保存，否则就会导致释迦果变黑变硬，而且不能再被催熟了。 | 收到后一般2-5天，不超过10天，表皮发黑即可食用 |   |
| 牛油果 | 如果表皮颜色呈现深绿，且按压手感柔软，就是成熟了，如果手感比较硬就是没有成熟。 催熟方法： 想快速催熟牛油果，最好的方法就是用家中已经熟透的水果来催熟它，做的时候最好准备一个干净的泡沫箱，再准备一个可以密封的保鲜袋，然后准备熟透的苹果或梨，把他们一起装入到保鲜袋装，把保鲜袋密封好，随后装入到泡沫盒中，把它放在温暖环境中催熟2~3天以后牛油果就能熟透变软（20℃以上环境）。 | 收到后一般3-7天，不超过14天 | 若有存储需要，未成熟果实可在4-8℃储藏温度下储藏20天，已成熟未切开的果实可在4-8℃储藏温度下储藏3-5天。 |
| 菠萝 | 将商品置于20℃以上干燥环境内催熟，也可将其与适量成熟苹果或香蕉（可释放乙烯）置于一处进行催熟。 菠萝无生熟之分，青皮一般较为脆酸爽口，黄皮较为细嫩软甜，可依据个人口感偏好对其进行催熟。 | 收到后一般催熟2-5天，不超过14天 | 切开后的果实务必尽快食用，未食用部分请放入冰箱并当天食用完。 |
| 香蕉 | 将商品与适量成熟的苹果或香蕉（可释放乙烯）置于同一密封袋中，在20℃以上环境内催熟，表面若出现水汽，请及时擦除；或在将商品放入密封袋之前使用废旧报纸将其包裹（废旧报纸有一定的吸水性）。 若轻捏果体发现不再硬实，且按压处已出现轻微变形，即使果体特殊香气及发软不明显，也已成熟。 | 收到货后一般催熟4-7天，不超过14天 | 果实一旦变软，务必尽快食用。 |

2.3消费者行为规范
2.3.1消费者在签收商品前应对商品当面验收（可采取录视频等方式留存证据），检查货物外包装及内物外观，在确定货物完好无损后进行签收；如有质量问题的消费者可当场拒收、留存快递单、发货单等，并及时联系商家处理。如物流公司不支持先验货再签收，请致电商家协商。如消费者无法当面验收，经快递员电话确认放在自提点、自提柜的，应当视为商家已向消费者交付商品，消费者应及时取回快递避免食品变质，因消费者使用或保管不当导致出现质量问题、变质的商品，美团电商将不受理此类退货、补货等要求，消费者自行与商家协商解决。（合理）
2.3.2生鲜类商品，消费者无正当理由拒绝签收、退货或因个人原因（地址错误、无人签收、关机、停机、不接电话等个人原因）造成快递无法及时送达，导致商品出现损伤、变质、腐烂、死亡情形的，相关运费及商品相应风险由消费者承担，买卖双方另有约定的，从其约定。

## **第三章 生鲜类商品纠纷举证**
3.1如消费者主张生鲜商品存在质量问题、描述不符、违背承诺等情形的，消费者可提供交易快照、美团电商在线客服工具聊天记录、验收商品图片、完整的拆包视频、留存快递单和发票等；（合理）
3.2举证时效和内容：

| 场景 | 反馈时效 | 举证内容 |
|---|---|---|
| 商品化冻、涨包、变质 | 签收时间+24小时 | 消费者提供收到产品化冻的图片证明 |
| 鲜活问题 |   | 消费者提供收到产品的图片 |
| 催熟期外未熟 | 签收时间+7天 | 消费者提供收到产品未熟的图片（肉眼可见的明显未熟） |
| 需催熟水果催熟期内腐烂 | 签收时间+5天 | 消费者提供产品腐烂的图片（需整体拍照可确认腐烂比例，腐烂商品和完好商品分开放置） |
| 水果腐烂 | 签收时间+48小时 | 消费者提供产品腐烂的图片（需整体拍照可确认腐烂比例，腐烂商品和完好商品分开放置） |
| 缺斤少两 | 签收时间+48小时 | 消费者提供实际收到产品的称重（与订单宣传重量比较，如商家没有明确说明，默认宣称重量为净含量） |
| 品种不符 | 签收时间+48小时 | 消费者提供收到产品的图片（例如：①产地不符，可提供收到的产品包装显示产地与订单实际宣传产地对比；②猫山王榴莲参照生鲜品类专业知识库对比判断；） |
| 大小问题 | 签收时间+48小时 | 消费者提供图片证明，包括：果径＜页面宣传，或者单果重量＜页面宣传，若页面未宣传大小，可参照辅助要求判断（如商家在商品详情页没有明确说明果径测量方式，平台将按照普通用户对果径的理解，进行判断和处理） |
| 无法通过外观判断商品腐烂变质（水果坏心、鸡蛋变质） | 签收时间+5天 | 消费者提供产品腐烂的图片 |

3.2.4若商品的性状极易受时间、环境等客观因素影响而发生质变，消费者逾期未举证的，美团电商不予受理。 
3.3收到商品的时间以快递公司系统内记录的签收时间为准。任意一方对签收时间存在异议时，若商家已按照2.1.2的要求进行发货的，需由提出异议的一方对实际签收时间进行举证；若商家委托物流未按照2.1.2的要求进行发货的，需商家对实际签收时间进行举证。
3.4时效界定： 
24小时的界定：自签收商品起计24小时内。
48小时的界定：自签收商品起计48小时内。
3.5买卖双方对举证时间、方式另有约定的，以买卖双方约定为准。

## **第四章 生鲜类商品****纠纷判责标准**
4.1配送问题
4.1.1消费者在商家发货前取消订单，商家应在取得消费者同意后再发货，否则消费者要求退货退款的，商家应向消费者全额退款（若订单中无法直接查询到取消订单的相关信息记录，需消费者提供发货前与商家沟通不发货的记录）；
4.1.2商家超时发货（物流信息以快递官网为准）的，依据《美团电商发货规则》中的延迟发货处理；
4.2质量问题
生鲜类商品存在腐烂、重量短缺、大小不符三类情形的，分别作以下处置：
4.2.1生鲜类商品存在腐烂、重量短缺、大小不符的，按其数量占商品总量的比例作部分或全部退款处理，具体判定如下：（迭代）
为保障消费者权益及合理减轻或免除消费者举证门槛，提升商家售后服务质量，美团电商将基于数据能力，通过对商家过往经营情况、处罚数据、**消费者举证/投诉/评价/反馈、**质量抽检、新闻媒体曝光等单一或多项数据进行研判，认定消费者所购商品存在质量问题等情形，平台有权根据严重情况对该订单做部分退款或全部退款处理。
赔付标准

| **问题程度** | **退款比例** |
|---|---|
| 程度≤50% | 按订单实际支付金额的50%退款 |
| 程度＞50% | 按订单实际支付金额的全额退款 |

4.2.2生鲜类商品存在腐烂、重量短缺、大小不符情形，且情节严重的，美团电商将视商品实际情形做出退货退款或退款处理。情节严重情况主要指如下：
4.2.2.1商品大小不符、重量短缺及腐烂三类情形两两并存的；
4.2.2.2商品存在大小不符或腐烂情形的，其数量超过商品总量百分之五十的；
4.2.2.3商品存在异味、化冻、商品涨包/漏气等无法食用等情形的；
4.2.2.4商家店铺内大量存在上述商品责任情形的。
4.2.2.5消费者投诉食用商品导致健康受到损害的。
除以上条款外，对本条内容买卖双方另有约定的从其约定。
特殊品类：
若生鲜类商品存在重量短缺，按短缺部分作相应比例部分退款；其中，针对特殊品类要求如下：

| **品类** | **问题程度** | **退款比例** |
|---|---|---|
| 鲜（生）榴莲 | 程度≤10% | 按订单实际支付金额10%退款 |
|   | 10%<程度≤30% | 按订单实际支付金额的50%退款 |
|   | 30%<程度 | 按订单实际支付金额的全额退款 |

其中关于“问题程度”，平台有权结合商品反馈及消费者举证，依据普通人的认知水准及日常经验，根据气候、商品类型等因素对问题比例和严重程度进行合理判断，若生鲜商品腐烂流汁的，被流汁污染导致无法食用的部分视为腐烂，计入腐烂数量，除以上条款外，对本条内容买卖双方另有约定的从其约定。
4.3描述不符问题
如消费者所收到的商品与商家页面宣传不一致，经平台判定商责后，美团电商有权要求商家为消费者进行包括但不限于补发、换新、退款处理。
4.4商品发错货
如消费者所收到的商品与订单完全不符，商家出现发错货情形的，商家需为消费者进行换货、补发处理。
4.5以上情况，问题较轻时美团电商优先与消费者联系，必要时美团电商可优先通过用户全部/部分退款申请或做适当补偿，相关费用由商家承担。（合理）
4.5.1如因以上质量问题产生纠纷，相关运费及商品相应风险由商家承担。若商品已不适宜退货，则作退款处理，货物由商家自行联系消费者协商处置或建议消费者作报废处置，如已建议消费者报废处置或已为用户退款，消费者因自行食用引起的安全问题，由消费者自行承担责任。
