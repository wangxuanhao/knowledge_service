# 美团电商商品差评管理规则

版本 V5.0

## **第一章 适用范围**
本规则适用于所有入驻美团电商商家所售商品。

## **第二章 定义**
**2.1 商品差评：**指消费者针对订单商品品质给出的评分小于3分的订单；
**2.2 商品****差评率****计算方式：【**商品评分小于3分的订单量/ 签收订单量 】×100%。**第三章 ****差评考核****规则**

### **3.1命中规则**

| **时间范围** | **考核条件** | **命中规则** | **处理措施（立即执行）** |
|---|---|---|---|
| 近30天 | 近30天订单量≥50单，商品差评量≥3单，差评率≥1.5倍近30天三级类目均值 | 累计命中1次 | 处违约金50元 |
|   |   | 累计命中2次 | 处违约金100元 |
|   |   | 累计命中3次 | 商品下架 |
|   | 近30天订单量＜50单，商品差评量≥2单，差评率≥1.5倍近30天三级类目均值 | 累计命中1次 | 处违约金50元 |
|   |   | 累计命中2次 | 商品下架 |


### **3.2问题商品监控**
在一个监测周期内，被商品差评规则命中频次较高、消费者品质体验较差的商品，商家需要重点关注，就消费者反馈问题制定改善措施；
**对已收到违规限制的商品品质情况仍未有效改善、或被品质体验较差命中频次较高、消费者品质体验长期处于尾部的商品，将会在监测周期结束时，被追加包括但不限于商品****流量降权****50%7天，商品****流量降权****100%7天，限制商品活动7天（对已参加活动的商品剔除活动并限制活动提报，对未参加活动商品限制活动提报），或处以店铺近30天销售额1%的罚金等。**

### **3.3考核周期**
数据周期：考核上周日（包含）及前30天数据
考核周期：每周一次
执行周期：每周二

### **3.4规则发布和生效时间**
规则在2025年09月17日开始公示，2025年09月24日生效。
