# **《****美团闪购商户售后服务规范****》**

## 第一章 总则 

### 一、【概述】 
（一）为保障用户的合法权益及购物体验，提升美团闪购平台商户的售后服务标准，保障买卖双方交易顺利完成，促进平台内商户的健康良好发展，现根据国家现行法律、法规、规章等规定，以及美团闪购平台与商户间协议和美团闪购平台发布的其他规范/规则/管理办法等，制定本规范。
（二）商户在美团闪购内的任何售后服务行为应当遵守本规范，根据法律规定、平台规则要求或对用户的承诺，履行对用户的服务义务。提供的售后服务包括但不限于处理用户发起的服务请求或平台协助用户发起的服务请求，履行对商品的退货、退款等相关规定要求或商户承诺的服务以及其他与售后相关的服务。同意美团闪购平台有权对商户的售后服务行为进行指导与管理，同意美团闪购有权对任何违反本规范发生不当售后服务行为的商户采取治理和处罚措施。

### 二、【适用范围】 
本规范适用于美团闪购平台的所有闪购商户及用户。

### 三、【定义】
【美团闪购平台】（以下简称“闪购平台”或“平台”）：美团旗下，提供即时零售（除医药外）的网络交易服务的第三方平台，为交易双方或多方提供网络经营场所、信息发布等服务，供交易双方或者多方开展交易活动。
【美团闪购商户】（以下简称“商户”）：指在美团闪购平台内开展经营活动并向用户提供非餐类（除医药外）商品/服务的平台内经营者。
【美团闪购用户】（以下简称“用户”）：指在美团闪购平台注册、接受平台规则，并可通过美团闪购平台与美团闪购商户达成订单的用户。
【用户责任】：指因用户个人原因发起退货、退款申请，包括但不限于买错、地址填错、商品不及预期等。
【商户责任】：指商户未按先前跟用户的约定履行对应的商品/服务承诺，（自配送订单用户因配送原因发起退货，视为商户原因）。
【平台责任】：指因平台原因导致用户发起退货、退款申请，包括但不限于因美团配送、平台系统原因。
【售后服务】：商户应根据法律规定、平台规则要求或对用户的承诺，履行对用户的服务义务。提供的售后服务包括但不限于处理用户发起的服务请求或平台协助用户发起的服务请求，履行对商品的退款、退货等相关规定要求或商户承诺的服务以及其他与售后相关的服务。
【极速退款】：指用户发起退款，当符合指定条件时，系统优先退款（具体内容见正文）。

## 第二章 商户售后服务细则

### 一、服务要求

| **订单环节** | **售后类型** | **服务要求** |
|---|---|---|
| 配送前 | 仅退款 | 一、用户因个人原因申请仅退款 （1）如满足平台极速退款条件，则系统自动审核通过退款； （2）如不满足平台极速退款条件，商户需在平台要求时效内根据商品是否影响二次销售等具体情况进行处理，若商户超时未处理，系统将会默认商户同意用户申请，由此产生的货损由商户承担。 二、用户因商户原因申请仅退款 （2）如不满足平台极速退款条件，商户需及时联系用户说明缺货、少货等影响正常履约的原因，并在平台规定时效内进行处理，若商户超时未处理，系统将会默认商户同意用户申请； （3）因商户无法正常履约导致的货损由商户自行承担。 三、用户因美团配送/平台原因申请仅退款 （2）如不满足平台极速退款条件，商户超时未处理，系统将会默认商户同意用户申请，涉及货损部分可向平台申请赔付。 |
| 配送中 | 仅退款 | 一、用户因个人原因申请仅退款 （1）如满足平台极速退款条件，则系统自动审核通过退款，订单配送类型为美团配送的商户，骑手将自动返货，订单取消后骑手长时间未返回商品，商户可在订单完成48小时内申请货损赔付，订单配送类型为美团跑腿和自配的商户需自行联系骑手返货； （2）如不满足平台极速退款条件，商户需依据实际情况在平台要求时效处理，如同意用户诉求，订单配送类型为美团配送的商户，骑手将自动返货，订单取消后骑手长时间未返回商品，商户可在订单完成48小时内申请货损赔付，订单配送类型为美团跑腿和自配的商户需自行联系骑手返货并处理退款申请且商户有权拒绝用户诉求，平台鼓励商户与用户协商并提供更宽松退款政策。 二、用户因商户原因申请仅退款 （2）如不满足平台极速退款条件，商户需在平台要求时效内处理，并告知用户无法继续配送或配送超时等无法继续履约的原因，用户可与商户协商重发商品或仅退款处理，若商户超时未处理，系统将会默认商户同意用户申请； （3）由此产生的相关费用及商品损毁、丢失、变质等风险由商户自行承担。 三、用户因美团配送/平台原因申请仅退款 （2）如不满足平台极速退款条件，商户超时未处理，系统将会默认商户同意用户申请，涉及货损部分可向平台申请赔付。 |
| 已送达 | 仅退款 | 一、用户因个人原因申请仅退款 （1）商户需根据实际情况在平台要求时效内判断是否同意用户申请，如判断需要将商品退回商户后退款，审核拒绝时应留言或联系用户告知，若商户超时未处理，系统将会默认商户同意用户申请。 二、用户因商户原因申请仅退款 （1）商户需根据实际情况在平台要求时效内判断是否同意用户申请，如判断需要将商品退回商户后退款，审核拒绝时应留言或联系用户告知，若商户超时未处理，系统将会默认商户同意用户申请，由此导致的货损由商户自行承担。 三、用户因美团配送/平台原因申请仅退款 （1）商户超时未处理，系统将会默认商户同意用户申请，涉及货损部分可向平台申请赔付。 |
|   | 退货退款 | 一、用户因个人原因申请退货退款 （1）商户应在平台规定初审时效内处理，遵循平台“7天无理由退货”规则判断商品是否符合退货要求，符合退货要求的应操作初审同意，若商户超时未处理，系统将会默认商户同意用户退货初审，商户无正当理由驳回退货申请，平台有权支持用户退货或退款； （2）商户同意用户退货申请后，用户应在商户初审同意后系统规定时效内选择合适的配送方式将商品退回至门店，因用户原因导致商品超时未退回门店，商户或平台有权终止本次退货流程，如用户仍需退货，可在售后效期内重新发起退货退款申请商户处理； （3）商户收到用户退回商品后，应在平台规定时效内完成商品查验，并同意退款，如发现商品不符合退货要求，应联系用户告知问题并协商商品处置方案，商户可拒绝退款。 二、用户因商户原因申请退货退款 （1）商户应在平台规定初审时效内处理，遵循平台“7天无理由退货”规则及其他商品售后规则等判断商品是否符合退货要求，符合退货要求的应操作初审同意，若商户超时未处理，系统将会默认商户同意用户退货初审，商户无正当理由驳回退货申请，平台有权支持用户退货或退款； （2）若商户判断商品不符合退货要求，应及时联系用户沟通核实情况，如发生纠纷可申请平台介入，并积极配合平台取证，如核实为用户原因造成商品无法退货的商户有权拒绝用户的退货主张，商品由交易双方协商返回用户或由商户处置； （3）商户在同意退货时附有合理条件的，用户退货时应符合该条件，若商户收到退货后发现商品不符合退款要求，有权拒绝用户退货退款终审； （4）商户不得私下诱导用户修改不符合事实的退货、退款原因，不得无故拒绝用户退货退款并诱导用户线下联系处理退货退款； （5）商户同意用户退货申请后，用户可选择四种退货方式，美团取退、自行送回、跑腿送回和商户取件，用户或商户应根据选择的退货方式在规定时效内将商品退回门店，因用户原因导致商品超时未退回门店，商户或平台有权终止本次退货流程，如用户仍需退货，可在售后效期内重新发起退货退款申请商户处理。 三、用户因美团配送/平台原因申请退货退款 （1）如商品未退还或退回后发现商品不符合退货要求，涉及货损部分可向平台申请赔付。 |
|   | 换货或维修 | 自商品签收后超过7天发生质量问题，用户可联系商户反馈并要求换货或维修，商户应遵守《中华人民共和国产品质量法》《中华人民共和国消费者权益保护法》《部分商品修理更换退货责任规定》等有关规定，提供部分商品“三包”期内换货、维修相关服务，如未提供升级平台介入，平台有权参考双方举证信息判责，如质量问题属实，平台有权支持用户退货、退款、赔偿违约金等合理诉求。 |


### 二、配送费承担规则

### （一）商品配送中发生退款，按照实际责任方承担配送费：
1、用户原因导致取消订单，用户实付配送费由用户承担，平台将在退款时扣除用户实付配送费；免配送费订单，配送费由补贴方承担；
2、商户原因导致取消订单，配送费由商户承担；
3、美团配送订单因配送原因导致取消订单，配送费由美团平台承担。

### （二）商品送达后发生退货退款，按照实际责任方承担配送费：
1、用户原因申请退货退款，正逆向配送费均由用户承担，免配送费订单，用户仅承担退回配送费；
2、商户原因导致退货退款，所有配送费均由商户承担；
3、美团配送订单因配送原因导致退货退款，所有配送费均由美团平台承担。

### 三、其他
（一）满足平台服务保障条件的订单，商户应优先按照对应服务标准规则执行，平台也将依据对应售后服务政策进行判责。平台服务保障规则包含《美团闪购“假一赔四/十”服务标签说明》《美团闪购“贵必赔”服务标签说明》《美团闪购榴莲“保四房”服务标签说明》《美团闪购“坏必赔”服务规范》《美团闪购“7天无理由退货”服务规范》《美团闪购冰品保障服务标签说明》等。
（二）极速退款包含未发货秒退款和配送中秒退款，未发货秒退款是指用户申请退款时，订单满足以下任一条件，系统优先退款（每个顾客每月即时单秒退次数至多为3次，预订单秒退次数至多为2次）；
1、骑手取货前，用户申请整单退款，且订单中商品均可二次销售，系统优先退款；
2、鲜花品类预订单，订单中包含不可二次销售商品且订单金额小于200元，T-1日下单预订单预计送达时间前8小时，当日下单预订单预计送达时间前2小时，顾客申请整单退款，系统优先退款；
3、非鲜花品类预订单，订单中包含不可二次销售商品且订单金额小于300元，预计送达时间前24小时，顾客申请整单退款，系统优先退款。
配送中秒退款是指用户申请退款时，订单同时满足以下条件，系统优先退款（每个顾客每月秒退次数至多为1次）。
1、整单商品均符合“7天无理由退货”；“7天无理由退货”标签范围详见《美团闪购“7天无理由退货”服务规范》
2、订单未送达且配送拦截成功；
3、订单金额≤500元。
（三）经平台判断属于以下场景导致用户退款的均归属为商户原因，平台将优先同意用户退款申请，具体场景包括：营业时间内商户未营业、商户发货慢导致配送超时、商户定位错误导致骑手无法按时取货、配送超时（自配送商户）、商品缺货、商户少送、商户错送、未送达指定地点（自配送商户）、商品未送到提前点送达（自配送商户）、骑手服务态度差（自配送商户）、骑手无法配送（自配送商户）、商品撒漏（自配送商户）等。
（四）经平台判断属于以下场景导致用户退款的均归属为美团配送/平台原因，平台将优先同意用户退款申请，商户可向平台申请影响二次销售货品的实际货值损失赔付。场景包括：配送超时、未送达指定地点、商品未送到提前点送达、骑手服务态度差、骑手无法配送、商品撒漏、骑手错送、骑手少送等。
（五）退货、退款过程产生争议时，双方可申请平台介入，平台有权按照《美团闪购交易纠纷处理规范》进行介入判责并处理。
（六）商户与用户达成退货协议后，若需要指定退货地址或多地址退货的，商户应征得用户同意后及时提供地址信息，否则，用户可选择平台给出的退货地址进行退货，退货后商品无法送达的风险由商户承担，同时交易支持用户退款，若商户提供的退货地址和原发货地不一致，导致用户退货的配送费增加的，其差额由商户自行承担。
（七）如平台介入判定商户无正当理由拒收商品的，平台有权为用户直接办理退款，商品由商户自行联系用户取回，由此产生的损失由商户承担。
（八）用户未经商户同意采取到付方式退货且商户已签收商品，若退货运费本应由用户承担的，则该到付产生的运费仍由用户承担。

## 第三章：商户消极售后类型与违规管控

### 一、类型

| 违规类型 | 违规定义 | 严重程度 |
|---|---|---|
| 违背约定或服务承诺 | 商户未按照约定或平台规定向用户提供相应的服务/商品，包括但不限于： 《美团闪购“假一赔四/十”服务标签说明》《美团闪购“贵必赔”服务标签说明》《美团闪购榴莲“保四房”服务标签说明》《美团闪购“坏必赔”服务规范》《美团闪购“7天无理由退货”服务规范》《美团闪购冰品保障服务标签说明》等。 | 重度 |
| 无故驳回合理服务诉求 | 商户无故驳回用户提出的与订单或商品相关的合理服务诉求，包括但不限于： 商户不处理用户的合理服务诉求或直接引导其联系平台或第三方； 商户无正当理由拒绝用户售后申请； 商户或平台同意用户的退货申请，用户将商品返回至门店地址后，商户无故拒收或拒绝退款。 | 重度 |
| 要求用户承担额外费用 | 商户与用户协商处理退货、退款时要求用户承担不符合平台规则的费用，包括但不限于： 1、用户原因退货、退款 商户要求用户承担正向配送费金额超过订单实际支付配送费金额（免配送费订单用户仅承担退回配送费）； 商户要求用户承担商品折旧、平台佣金、打包费等额外费项（因用户丢失或损坏商品/发票/附件/包装，商户要求用户承担合理损失除外）。 2、非用户原因售后 商户要求用户承担商品配送费、商品折旧、平台佣金、打包费等额外费项（因用户丢失或损坏商品/发票/附件/包装，商户要求用户承担合理损失除外）。 | 中度 |
| 售后原因虚假 | 商户诱导用户选择非真实原因申请售后、取消订单、或商户申请售后原因与实际情况不符等行为。 | 中度 |
| 无故引导用户线下退货或退款 | 商户引导用户通过非平台提供的第三方渠道（微信、支付宝等）处理退货、退款，以下特殊情形除外： 用户有退款外的其它商品或服务方面的定制需求需要专项沟通； 需要用户承担合理的配送费或损失费用，且与用户沟通一致； 用户无法申请退款或退货时，主动联系商户处理； 商户账户异常导致线上无法退款成功。 | 重度 |
| 处理售后超时 | 因商户问题导致的商户处理用户退货、退款申请初审/终审超过平台规定时效。 | 中度 |
| 消极服务用户 | 商户通过电话或IM服务用户时，被平台判定为消极服务，包括但不限于： 商户存在包括但不限于提供虚假无效的电话号码、联系电话状态异常（如停机等）、营业时间内接通率异常、无故拉黑/屏蔽用户电话号码等情形； 商户IM超3min不回复； 商户电话/IM回复内容重复机械、答非所问。 | 中度 |
| 拒绝配合平台取证 | 商户拒接平台客服回访电话，或在平台客服介入纠纷处理过程中，不配合平台客服提出的合理举证要求。 | 重度 |


### 二、违规管控
商户消极售后，包括但不限于不规范处理售后服务单、无故拒绝售后服务等场景，美团闪购有权按照《美团闪购商户违规管理规则》《美团闪购商户交易服务管理规范》中条款进行相应处理。商户售后服务过程中出现上述消极行为，或因商户原因售后导致用户投诉，根据违规情节严重情况，平台有权按照相关规则中的相应条款介入，同意用户退货、退款主张，扣除违约金等处罚手段。
（一）若商户出现消极服务用户、诱导用户修改售后原因等中度违规，平台有权根据商户服务情形，扣除订单实际支付金额的5%作为商户违约金，单次处罚最低不少于5元，最高30元；
（二）若商户存在无故拒绝售后等重度违规，平台有权根据商户服务情形，扣除订单实际支付金额的10%作为商户违约金，单次处罚最低不少于10元，最高50元；
（三）若商户在一定周期内多次发生违规且超过一定阈值，将被限制售后处理权限，期间用户申请售后平台将依据问题类型、商品状态判断直接介入处理；
（四）若商户被大量用户投诉或给用户或平台造成较大资金损失的，平台有权采取限制成交、冻结货款，解除协议，终止合作，停业整顿等平台认为必要的处理手段。

## 第四章 附则

### （一）规范溯及力
美团闪购商户的行为，发生在本管理规范生效之日以前的，适用当时的规范。发生在本管理规范生效之日以后的，适用本规范。

### （二）规范效力
商户应遵守国家法律、行政法规、部门规章等规范性文件。对任何涉嫌违反国家法律、行政法规、部门规章等规范性文件的行为，本规范已有规定的，适用于本规范。本规范尚无规定的，美团闪购有权酌情处理。但美团闪购对商户的处理不免除其应承担的法律责任。商户在美团闪购的任何行为，应同时遵守与美团闪购及其关联公司签订的各项协议及平台规范。

### （三）规范变更
美团闪购可根据平台运营情况随时调整本管理规范并向商户公示。

### （四）规范冲突 
平台有权针对特定交易形式、交易环节或商品品类等，在本规范基础上制定下位规则（包括但不限于规则、规范、信息公告、规则中心文档、商户后台通知、帮助中心文档、行业标准等）。下位规则属于本规范的组成部分，与本规范具有同等效力。若下位规则与本规范存在冲突，优先适用下位规则；若下位规则之间存在冲突，优先适用发布在后的规则。

### （五）无规定处理
适用本规范的所有对象应遵守国家法律、行政法规、部门规章、地方法规等规范性文件。对任何涉嫌违反国家法律、行政法规、部门规章、地方法规等规范性文件的行为，本规范已有规定的，适用于本规范。本规范尚无规定的，闪购平台有权依法处理。

### （六）生效
本规范首次发布日期为2025年2月21日，2025年3月6日正式生效。
