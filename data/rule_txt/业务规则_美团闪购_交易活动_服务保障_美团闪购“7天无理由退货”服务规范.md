# **美团闪购****“7天无理由退货”服务规范**

## **第一章 总则**

### **一、【概述】 **
（一）为规范美团闪购平台商户服务经营行为，营造合法合规的平台经营环境， 保障消费者的合法权益，促进平台内经营者的健康良好发展，维护美团闪购平台的正常经营秩序，根据国家法律法规规章，以及美团闪购平台与商户间协议和美团闪购平台发布的其他规范、规则、管理办法等，制定本规范。
（二）商户在美团闪购平台内的任何经营行为应当遵守本规范。商户同意美团闪购平台有权对商户经营行为进行指导与管理，同意美团闪购有权对任何违反本规范发生不当行为的商户采取规则管控措施，商户应配合平台依据监管部门要求依法依规对商户采取的暂停/停止服务等措施。

### **二、【适用范围】 **
本规范适用于美团闪购平台的所有闪购商户和用户。

### **三、【定义】**
（一）美团闪购平台（以下简称“闪购平台”或“平台”）：指美团旗下提供即时零售（不含医药）的网络交易服务的第三方平台，为交易双方或多方提供网络经营场所、信息发布等服务，供交易双方或者多方开展交易活动。
（二）美团闪购商户（以下简称“商户”或“商家”）：指在美团闪购平台内开展经营活动并向用户提供非餐类（不含医药）商品/服务的平台内经营者。 
（三）美团闪购用户（以下简称“用户”）：指在美团闪购平台注册、接受平台规则，并可通过美团闪购平台与美团闪购商户达成订单的消费者。
（四）“7天无理由退货”服务：指用户购买带有“7天无理由退货”服务标签的商品后，自商品送达之日起7天内（自订单确认送达时间起计算满168小时为7天），对支持“7天无理由退货”且符合完好标准的商品可发起退货申请，符合“7天无理由退货”服务条件的商户须在规定时效内履行退货退款服务承诺。

## **第二章 服务标签适用范围及分类**

### **一、“7天无理由退货”服务适用商品分类**

| **是否适用“7天无理由退货”** | **商品类型** | **举例说明** |
|---|---|---|
| 不适用“7天无理由退货” | 定制类商品 | 定制花束、定制文具、定制线材、设计服务、合约机等 |
|   | 鲜活易腐类商品 | 鲜花绿植、水产肉类、新鲜蔬果、活体类、冷藏冷冻商品等 |
|   | 在线下载或者用户拆封的音像制品、计算机软件等数字化商品 | 充值点卡、加油卡等 |
|   | 交付的报纸、期刊 | 期刊杂志等 |
|   | 服务类商品 | 家电服务、延保服务等 |
|   | 其他根据商品性质并在用户购买时确认不宜退货的商品 | 黄金等贵金属价格波动大的商品、酒类等 |
| 商户可选支持“7天无理由退货” | 拆封后影响人身安全或者生命健康的商品，或者拆封后易导致商品品质发生改变的商品 | 食品、内裤、塑身裤、塑身连体衣、乳贴、插片/胸垫、婴用品、个护美妆等贴身或入口类商品等 |
|   | 一经激活或者试用后价值贬损较大的商品或非生活消费所需的商品 | 数码家电、智能设备、商用厨具、工业品、办公耗材等 |
|   | 在用户购买前已明示其质量、性能、用途和有效期限等状况的商品 | 销售时已明示临近保质期/有瑕疵的商品、二手商品等 |
| 适用“7天无理由退货” | 除上述类型外的其他商品 | 如服饰鞋靴、箱包、日百类等，无使用痕迹，无洗涤、无损、吊牌未摘的商品等 |


### **二、服务承诺标签分类**
平台将按照商品类型设置对应的标签，不同的商品类型可能展示不同的标签，具体标签如下：

| **标签分类** | **标签说明释义** | **商品举例** |
|---|---|---|
| 7天无理由退货 | 商品支持送达后的7天内在商品完好不影响二次销售的情况下由于用户原因申请退货 | 如箱包类等，无使用痕迹，无洗涤、无损、吊牌未摘等 |
| 7天无理由退货（拆封后不支持） | 商品一次性包装未拆封支持送达后7天内由于用户主观原因申请退货，如商品一次性外包装或商品包装有防撕贴、密封贴及其他具备唯一性或纪念意义的标记已拆封等任一商品不完好情形，均不适用7天无理由退货 | 如美妆、个护清洁、母婴、食品类等商品，商品塑封膜完好（若有）、密封包装完好（若有）、商品瓶盖未打开等 |
| 7天无理由退货（安装后不支持） | 未安装的商品支持送达后7天内由于用户主观原因申请退货，如商品已安装，均不适用7天无理由退货 | 如健身车、踏步机、挂装空调、油烟机、热水器等需要安装的商品 |
| 7天无理由退货（激活后不支持） | 未激活的商品支持送达后7天内由于用户主观原因申请退货，但商品已激活或有被授权记录等任一不完好情形，均不适用7天无理由退货 | 如笔记本、台式机、手机、PS4有激活限制的商品等 |
| 7天无理由退货（使用后不支持） | 未使用的商品支持送达后7天内由于用户主观原因申请退货，但商品已使用、已穿戴、有不可恢复的数据使用记录、电器过水等任一不完好情形，均不适用7天无理由退货 | 如汽车洗车机、电子熏香、汽车香水等 |
| 7天无理由退货（定制类不支持） | 非定制类的商品支持送达后7天内由于用户主观原因申请退货，但定制类商品不适用7天无理由退货 | 如定制家居、定制服装、定制花卉、定制文具日百等 |


## **第三章 服务要求**

### **一、服务申请条件**
用户需满足以下条件，方可申请“7天无理由退货”服务：
1、用户购买的商品带有“7天无理由退货”服务标签；
2、用户个人原因产生的退货诉求；
3、用户应确保退回的商品完好不影响二次销售，商品完好的标准如下：
①商品能够保持原有品质、功能；
②退回商品和相关配（附）件（如吊牌、说明书、三包卡等）齐全，并保持原有品质、功能，无受损、受污、刮开防伪、产生激活（授权）等情形，无难以恢复原状的外观类使用痕迹、不合理的个人使用数据留存等数据类使用痕迹；
③用户基于查验需要而打开商品包装，或者为确认商品的品质、功能而进行合理的调试不影响商品的完好。若商品包装客观上确有防伪性、唯一性、防撕性、收藏纪念价值等存在特殊附加价值的，商户可在合理范围内提出特定的包装保护要求，对于合理可行的包装保护要求，商户应进行显著明示，未明示的按照普通包装处理。经商户事前显著明示后，用户应予积极谨慎保护。若该类包装损坏程度足以造成价值贬损或功能丧失，可认定其商品价值贬损。
④商户事先对于完好标准有特定补充要求且显著说明的，以具体说明为准，包括特殊品类的“7天无理由退货”标签括号说明中标注的要求。
4、用户已成功购买且未完成退货退款的商品；
5、用户成功下单且自商品送达之日起7天内（自订单确认送达时间起计算满168小时为7天）发起的退货申请。

### **二、不支持申请服务场景**
当用户因个人原因主张退货时，由商户证明或平台判断用户属于包括但不限于以下行为场景时，有权驳回该申请：
1、用户申请退货的商品不适用“7天无理由退货”（具体见第三章 “7天无理由退货”服务适用商品分类）；
2、用户未在规定时间内申请退货；
3、用户退回的商品不符合完好标准，已影响二次销售的；
4、用户在申请服务前已成功完成退货退款；
5、用户蓄意利用此服务违规获利；
6、用户以非正常生活消费为目的而生成的订单；
7、其他非正常消费或申请服务或存在其他违法违规行为的情况。

### **三、服务申请流程**
1、用户购买的商品符合“7天无理由退货”服务条件时，需线上申请或联系商户申请退货退款，商户将在平台规定时效响应并提供对应服务。
2、用户在提交服务申请时，须提供商品完好的凭证，证明材料包括但不限于： 商品完好的实拍图或视频（需包含商品包装及订单信息）。
3、商户收到退货申请后应当及时向用户提供真实、准确的退货地址、退货联系人、退货联系电话等有效联系信息。
4、用户应在商户同意退货申请后48小时内将商品退回至商户，商户在收到退回商品后48小时内处理并操作退款完成。

### **四、商品退货要求**
1、用户退货时应当将商品、原包装（如有）、其配（附）件、赠品（如有）、纸质发票（如有）等一并退回。
赠品包括赠送的实物、积分、代金券、优惠券等，如赠品因遗失、破损等原因不能一并退回，商户可要求用户按照事先标明的赠品价格支付赠品价款。
发票因遗失、损坏等原因不能一并退回，不影响商品退货，但用户须承担相应税款。
2、如商户收到用户退回的商品，拆包查验发现商品已不符合完好标准且影响二次销售，须及时主动联系用户并与用户协商商品处理方式。若用户原因导致所退回的商品不符合商品完好标准，且商品需返还用户的，产生的配送费由用户承担。
3、用户原因申请“7天无理由退货”的，若订单商品商户免配送费（指正向配送：商品由商户配送到用户的过程），用户仅承担退回商品配送费即可；若订单商品未免配送费或商户对免配送费商品设置了附加条件（如配置了免配送费门槛），用户退货后导致无法满足免配送费要求，将由用户承担订单相关的商品配送费和商品退回配送费，若双方有额外约定，从其约定。

## **第四章 服务保障**
1、用户提交“7天无理由退货”申请后，商户应及时处理退货及退款事宜，退货价款以用户实际支出的价款为准。
2、订单全额退款的，下单时所使用的优惠券、代金券、红包、积分等将退回，有效期以卡券红包页面展示为准；订单部分退款的，下单时所使用的优惠券、代金券、红包、积分等不再退还。有特殊规定的，优先适用特殊规定。
3、商户未履行承诺或用户不认可商户处理结果的，用户可联系平台客服或在订单上操作申请平台介入，同时应提供商户未履行承诺或商户拒绝履行承诺的证明材料，经平台核查用户购买的商品符合“7天无理由退货”服务申请条件时，平台有权按照标准直接操作退货、退款，如给用户造成损失要求赔付的，相关损失由商户承担。用户未提供证明材料或提供的证明材料不足的，商户或平台有权驳回其申请。
4、平台要求必须支持“7天无理由退货”的商品，商户单方声明不支持“7天无理由退货”的行为无效。平台鼓励商户向用户提供更优于本规范要求的“7天无理由退货”要求。
5、商户应按照国家法律法规要求提供“7天无理由退货”服务，对于违反国家法律法规、平台规则的商户平台将进行管控。

## **第五章 附则**

### **一、【规范变更】 **
平台有权对本规范内容进行修改、补充或更新，并在该规范生效前通过美团闪购商家中心、美团闪购平台公告、美团闪购规则中心等方式予以公告，上述公告一经发布即视为已经单独通知到每一家使用美团闪购服务的商户；若商户在本规范内容修改、补充或更新公告后继续使用美团闪购提供的服务，即视为商户同意遵守修改、补充或更新的规范。

### **二、【规范效力】 **
本规范作为商户与闪购平台所签署协议的附件，与协议具有相同法律效力。商户违反本规范的，按照本规范、双方协议及其他管理规范进行处罚。

### **三、【规范冲突】 **
平台有权针对特定交易形式、交易环节或商品品类等，在本规范基础上制定下位规则（包括但不限于规则、规范、信息公告、规则中心文档、商家后台通知、帮助中心文档、行业标准等）。下位规则属于本规范的组成部分，与本规范具有同等效力。若下位规则与本规范存在冲突，优先适用下位规则；若下位规则之间存在冲突，优先适用发布在后的规则。

### **四、【无规定处理】**
适用本规范的所有对象应遵守国家法律、行政法规、部门规章、地方法规等规范性文件。对任何涉嫌违反国家法律、行政法规、部门规章、地方法规等规范性文件的行为，本规范已有规定的，适用于本规范。本规范尚无规定的，闪购平台有权依法处理。

### **五、【规范溯及力】 **
发生在本规范生效之日前的行为，适用当时的规范进行处理；发生在本规范生效之日后的，适用本规范。

### **六、【可分性】 **
如果本规范中任何一条被视为废止、无效或因任何理由不可执行，该条应视为可分的且并不影响任何其余条款的有效性和可执行性。

### **七、【生效】 **
本规范首次发布日期为 2024年4月11日，自2024年4月25日生效。于2024年7月16日第2次修订并发布，修订后版本自发布之日起生效。
