# **美团闪购****“****坏必赔****”服务规范**
请您仔细阅读、充分理解本服务规范的全部内容，并审慎决定是否在相应类目内经营或提供“坏必赔”服务。如您发布相应类目商品，或实际使用“坏必赔”服务标识的，则视为您已经阅读、理解并同意本服务条款之全部内容，并自愿受其约束。如您不同意本规范内容，请您及时停止经营相应类目。

### **第一条 【适用范围】**
适用于所有加入“坏必赔”服务的美团商家。

### **第二条 【定义】**
“坏必赔”服务是指当用户在美团闪购上购买带有“坏必赔”服务标识的商品后，若收到商品后发现存在不新鲜、变质发霉、腐烂、明显损伤等影响正常使用等情况，可以在商品送达的保障时效内依照本规范发起服务申请，卖家需履行相应的服务承诺。

### **第三条 【准入及准出标准】**
一、开通：经营“水果、蔬菜/豆制品、海鲜水产、生肉/生禽/生蛋、熟食/鲜食”类目商品的商家默认开通“坏必赔”服务，并按照承诺为消费者提供相应售后保障服务。
二、退出：商家退出平台或下架商品时同时退出“坏必赔”服务。退出生效前产生的订单，商家仍需按照“坏必赔”服务规定履行服务。

### **第四条 【服务承诺要求】**

### **1、响应时效**
如果买家在收到商品后的，以“商品质量有问题、商品包装损坏/漏撒、商品与描述不符（缺斤少两、图片不符等）”等描述商品品质存在问题为理由发起仅退款售后服务申请，则部分满足条件容易判责的售后申请将由平台直接审核，其余售后申请仍将由商家进行审核。对于流转至商家审核的售后申请，若用户在营业时间内发起的，商家需在规定时效内处理用户的售后请求，若商家未在规定时效内处理，平台将默认接受该服务申请。

| 商品类目 | 保障时效 |
|---|---|
| 水果 | 收货后24小时内 |
| 蔬菜/豆制品 | 收货后24小时内 |
| 海鲜水产 | 收货后6小时内 |
| 生肉/生禽/生蛋 | 收货后24小时内 |
| 熟食/鲜食 | 收货后24小时内 |


### **2、服务承诺覆盖问题场景范围**

| **问题场景** | **问题场景说明** |
|---|---|
| 变质/发霉 | 商品内部/外部出现明显的腐烂、流水液化、黑心烂心，冻伤，烧核，发芽，虫洞虫孔，霉点、霉斑、菌丝等问题属于变质发霉。 |
| 食品不新鲜 | 商品无变质腐烂、发霉等情况，但有打蔫、干枯、水分流失导致的褶皱等情况。 |
| 食品不熟 | 包含但不限于以下场景： 1.因未成熟导致口感生涩/发硬/味道酸涩； 2.熟食类商品不易咀嚼、渗血、有红血丝等。 |
| 商品破损 | 商品损坏指商品外包装或商品本体出现非划痕、污渍等瑕疵问题的损坏。 |
| 商品撒漏 | 商品撒漏指商品内容物从包装内掉出或撒漏。 |
| 存在异物 | 食品中出现以下异物： 1.无生命体：在食品制作过程中可能会混入的小型物品，例如人、动物、植物的残留物，如鸡蛋壳、头发等。 2.有生命体：如昆虫类，包括苍蝇、飞虫等。 3.无害物品：未使人受伤的物品，如厨房用品（钢丝球、线、木头等）和其他物品（泥沙、胶带等）。 |
| 其他商品质量问题 | 其他商品不新鲜、变质发霉、腐烂、明显损伤、描述不符等影响正常使用等类似问题。 |


### **3、服务承诺退赔金额比例**
1）符合坏品判定标准的商品比例大于0%，小于或等于10%的，按照该商品实付金额的10%进行部分退赔；
2）符合坏品判定标准的商品比例大于10%，且小于或等于30%的，按照该商品实付金额的30%进行部分退赔；
3）符合坏品判定标准的商品比例大于30%，且小于50%的，按照该商品实付金额的50%进行部分退赔；
4）符合坏品判定标准的商品比例在50%及以上的，按照该商品实付金额的全额退赔。
如无法明确判断比例问题，平台有权对问题商品的情况做出独立判断，并有权要求双方补充相应凭证，商家应配合平台提出的要求执行相应退赔，商家与消费者就退款/赔付金额另有约定的，按双方约定处理。

### **第五条 【服务不支持场景】**
当用户申请“坏必赔”服务后，由商家证明或平台判断用户属于包括但不限于以下行为场景时，商家有权通过进线商服电话4006005339申请货损：
1、对平台最终处理结果产生异议；
2、用户蓄意利用此服务违规获利；
3、用户以非善意申请服务或存在其他违规行为的情况。

### **第六条 【服务保障】**
1、商家未履行或未按照标准履行“坏必赔”服务承诺的，经平台介入判定商户违规属实，除按照标准直接从保证金或待结算款中扣除相应金额执行退赔外，平台有权采取包括但不限于商品下架、类目限售、违约金扣除、门店置休等处罚措施。
2、平台有权根据商家运营和服务质量、履约情况、商品类目、属性、店铺经营、违规、客诉等，决定是否对商家继续打标“坏必赔”服务（包括清退“坏必赔”门店或商品），具体以商家后台相应面显示及平台通知为准。
