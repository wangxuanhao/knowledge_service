# 美团APP商户评价诚信管理办法

美团作为本地生活信息及独立的第三方消费评价平台，不仅为用户提供商户信息、消费评价及消费优惠等信息服务，同时亦提供团购、餐厅预订、外卖及电子会员卡等O2O（Online To Offline）交易服务，美团旗下各产品已成为影响用户决策、商户品牌经营的重要平台，一个良好的平台环境无论对用户还是商户都变的尤为重要。
因此，为了保障商户与用户合法权益，维护平台正常的秩序，实现商户规范化运营，根据《中华人民共和国民法典》《中华人民共和国反不正当竞争法》《中华人民共和国广告法》政策法规及《商户入驻服务合同》《美团用户服务协议》等协议，特此制定《美团APP商户评价诚信管理办法_诚信分行业试点规范》（简称“本管理办法”）。 

### **《美团APP商户评价诚信管理办法》**

### **一、目的及适用范围**
为了给广大美团APP用户提供更真实、更客观的评价信息和商户信息作为参考，同时为广大商户提供公平公正的竞争环境，美团制定《美团APP商户评价诚信管理办法_诚信分行业试点版本》，携手商户共同抵制炒作虚假好评、恶意攻击竞争对手、骚扰用户、操控用户评价结果等扰乱平台评价秩序的行为。
适用范围：美团旗下美团APP到店体验类商户。

### **二、评价炒作／干扰平台评价秩序行为定义及处罚细则**
如商户违反本管理办法的规定，美团有权**视情形采取警告、限制部分平台功能等处理措施（包括但不限于影响评价功能、流量获取、星级数据等，最高可对门店进行清退），根据违规行为严重程度进行相应处罚**，违规行为定义及处罚细则如下，满分12分。

| **违规行为类型** | **违规行为定义及情节** | 扣除分值 |
|---|---|---|
| 恶意投诉或申诉 | 在被处罚后，提供虚假材料进行申诉。 | 2 |
| 商户及利益相关方在商户下写好评 | 商户、店员、亲友等利益相关方自行注册账号在商户下刷好评。 | 2~9 |
| 召集用户写不真实好评 | 商户自行或通过第三方召集用户刷好评； 商户自行或通过第三方批量注册小号刷好评。 | 2~9 |
| 组织用户免费体验换好评 | 商户私下自行或委托他人组织用户线下试吃、免费体验等活动，以换取好评。 | 3~6 |
| 利益诱导好评 | 商户通过利益如折扣、送菜、升级服务等作为交换诱导用户写好评。 | 3~6 |
| 要求用户写好评并引起反感或替代用户写好评 | 商户当面要求或强制要求用户写好评，引起用户反感； 商户使用用户账号替代用户写好评。 | 3~6 |
| 仿冒/违规开展官方活动 | 商户自行或通过第三方通过上传商户头图、冒用官方线下宣传物料、私下组织等方式，仿冒平台“美团美食榜”、“必吃榜”、“美团免单”等官方活动，扰乱平台秩序。 商户自行或通过第三方多次违反平台规则，不规范使用“美团美食榜”、“必吃榜”、“人气榜”、“好评榜”等官方荣誉物料且拒绝整改，扰乱平台秩序。 | 3 |
| 恶意攻击竞争对手 | 商户自行或通过第三方给竞争对手写恶意差评或回应。 | 3 |
| 恶意陷害竞争对手 | 商户自行或通过第三方通过刷好评陷害竞争对手（导致竞争对手被误罚）。 | 3 |
| 联系用户修改或删除评价 | 商户自行或通过第三方联系用户通过各种方式企图引导或要求用户修改或删除评价。 上述行为包括但不限于：通过利益交换（如退款、免费体验等）直接或间接引导用户对评价做出删除或修改。 | 3 |
| 误导用户给错误门店写评价 | 误导用户，致使用户将评论写到了错误商户。 | 3 |
| 使用违规手段删除或修改评价 | 包括但不限于商户自行或通过第三方伪造虚假凭证恶意投诉删除评价、盗取用户账号修改/删除评价等行为。 | 6 |
| 逃避处罚 | 通过修改商户信息等手段，恶意逃避处罚。 | 6 |
| 虚假报错门店信息或合并他人门店 | 商户自行或通过第三方提供虚假的证据材料，对已有的商户名、商户地址、电话等门店信息进行虚假报错或合并他人门店。 | 6~12 |
| 骚扰用户扰乱评价秩序 | 商户及其关联人员自行或通过第三方对写评价的用户进行骚扰、侮辱、恐吓等影响他人正常生活、工作秩序和安宁，干扰用户正常合理的评价权利，破坏平台正常经营秩序的行为； 上述行为包括但不限于通过电话、短信、邮件等方式实施骚扰、辱骂、恐吓的行为、未经授意擅自公开写评价用户的隐私信息、擅自到用户工作、生活场所要求删改评价等； 或为了达到如上目的，商户自行或通过第三方假冒用户身份等方式套取用户个人信息。 | 2~12 |
| 其他扰乱平台秩序/不正当竞争行为 | 商户通过以上违规类型以外的其他方式进行炒作好评、违规转移或删除差评、攻击同行、规避平台处罚等行为。 | 2~12 |

注意：处罚等级系针对商户违规行为进行处罚的区间，平台将视违规行为的情节、严重程度等因素，综合考虑并确定实施处罚的具体分值。

### **三、处罚等级及处罚措施**

|---|---|---|---|---|---|
|   | **处罚期****内评价****内容隐藏** | **商详页公示** | **星级隐藏** | **页面****排序降权** | **禁止上榜** |
| 2分 | 3天 | 3天 |   |   |   |
| 3分 | 7天 | 7天 |   |   |   |
| 6分 | 14天 | 14天 | 14天 |   |   |
| 9分 | 30天 | 30天 | 30天 | 30天 | 30天 |
| 12分 | 60天 | 60天 | 60天 | 60天 | 60天 |
| **再犯** | **暂停与商户的合作** |  |  |  |  |

1、再犯，是指商户从事本办法规定的违规行为累计被扣除12分后，在诚信分重置前，再次从事本办法规定的一类或多类违规行为。
2、商户星级和评分均为动态指标，系根据评价诚信度、评价质量、评价时间、评价数量等多种要素加权由系统综合计算得出。故针对部分违规商户，系统会剔除违规作弊数据后重新计算展示。
3、如商户行为涉嫌违反国家法律法规，美团将根据相关要求配合国家有关部门采取相应措施，包括但不限于将所掌握的信息移送给公安机关/市场监管等部门，并全力配合展开调查和打击工作等。
4、美团有权视情节选择对违规行为较为恶劣的被处罚商户进行公示。
5、针对恶意滋事，借“投诉”之名提出无理要求甚至以闹事等极端手段要挟美团工作人员，或者通过诸如暴力、威胁、胁迫、诽谤等其它违法手段扰乱社会公共秩序及市场竞争环境的商户，美团会依法依规予以举报、投诉，同时美团有权对相关商户在美团的门店进行删除或者屏蔽，甚至禁止商户通过任何方式使用美团旗下美团APP的商户信息展示服务。

### **四、累计和加重处罚规则**

### **1、违规行为累计：**
系统将对商户发生的违规行为进行记录并累积计算。即商户发生违规行为后再次发生违规行为（简称“累计违规”）将会触发累积计算规则，无论前次违规行为是否被处罚。

### **2、加重处罚规则：**
（1）若商户发生累计违规，则美团有权在常规处罚等级基础上对商户进行加重处罚。
（2）若美团对商户进行处罚后，在处罚期内商户再次违规，美团有权对商户进行加重处罚。加重处罚可以与原处罚一并执行也可以分开执行。
加重处罚的处罚等级需不低于二级，美团有权视违规行为的严重程度在常规处罚区间基础上提升一级或多级处罚，甚至可采取“下线门店”、“永不收录”等措施。

### **五、商户评价常见问题及解答**

### **1、申诉流程：**
**（1）如何申诉：**商户可登陆【开店宝】APP，点击“**首页-全部服务-店铺-诚信中心-美团-积分变动记录**”；美团工作人员在将收到商户申诉【**3个工作日内】**核实；若判定商户提供的证据成立，则取消相应扣分项及处罚（如有）并将结果告知商户；若判定商户提供的证据不成立，则将核实结果告知商户并维持原处罚。
**（2）申诉时效：**如商户认为美团对于商户判定存在扰乱评价秩序行为有误，商户需在收到美团通知商户存在扰乱评价秩序行为处罚起【**7个工作日】**内进行申诉，对扰乱评价秩序行为进行充分的举证和合理解释。商户在期间内未做申诉，则视为商户认同美团判定商户存在扰乱评价秩序行为，并放弃其主张权益。美团在收到商户申诉后，有权对商户提交的举证与解释进行审核，并自主根据审核结果做出判断与处理。同时，申诉期内，不停止根据本公约做出处罚行为。

### **（3）注意事项：①**如商户恶意申诉或提供虚假凭证，美团将依据本管理办法约定，扣除2分评价诚信分。②**商户在美团APP和点评APP的处罚体系是相互独立的，在美团APP的违规行为仅会****对美团****APP商户进行处罚。**
**2、处罚的权益如何恢复？**
（1）存在扰乱评价秩序行为受到处罚的权益，会在处罚期结束后进行恢复。
（2）商户可以针对有异议的处罚进行申诉，在申诉成功后，系统会恢复申诉成功的权益。
（3）在试点期间内，平台将根据不同行业设定一定周期的循环考核，在单个考核周期结束后诚信分分数重置：即所有商户的诚信分在考核周期结束后会恢复至满分12分。具体行业及单个考核周期的时长，以平台另行通知为准。

### **3、通知查看路径**
商户可登陆【开店宝】APP查看当前诚信分、诚信分变更记录及相应处罚记录：
（1）方式一：点击“消息-重要/预警-查看详情”进入美团APP诚信分页面；
（2）方式二：点击“首页-全部服务-店铺-诚信中心-美团”进入美团APP诚信分页面。
4、**扰乱平台评价秩序的行为如何排查和判定？**
（1）【人工排查及判定】商户应当按照诚实信用的原则经营，平台在收到投诉、举报，或取得可信的线索、证据的情况下，会安排人员对商户涉嫌扰乱平台评价秩序的异常情况进行排查。如商户被平台认定存在异常行为，商户必须做出合理解释和提供充分抗辩证据以证明其并未实施扰乱平台评价秩序行为，商户可按照【申诉流程】中要求进行申诉，申诉不成功的将被判定为扰乱平台评价秩序行为。
（2）【系统排查】因美团商户数量特别巨大，仅通过人工排查无法有效识别并遏制扰乱平台评价秩序行为。基于统计学和人工智能方法，美团研发了“扰乱平台评价秩序识别”系统。该系统可从账号的评价、交易、行为方式等多个维度对异常的数据进行排查。
（3）【系统判定】对于“扰乱平台评价秩序识别”系统排查出的异常数据，系统会在统计学基础上依据预先设定的先验经验作出是否属于扰乱平台评价秩序的判定。对于系统判定为扰乱平台评价秩序的行为，商户可按照申诉流程中要求进行申诉，申诉不成功的，美团可以依据系统判定结论对商户进行处罚。
（4）【判定信息披露】如商户的某行为被人工排查并判定构成扰乱平台评价秩序，美团可以视所涉信息的保密等级决定是否披露判定的依据。但是，在系统排查并判定商户行为构成扰乱平台评价秩序的情况下，鉴于“扰乱平台评价秩序模型”系统及其算法均为美团的核心商业秘密，平台会将初步证据和结论通知商户，而无法披露相应算法依据。
（5）【商户扰乱评价秩序的处理】美团应根据本管理办法和其他相关规则的规定对商户扰乱评价秩序的行为进行处理，美团将在通知商户构成扰乱评价秩序的同时将处理结果一并告知商户。

### **六、附则**
1、对于本管理办法生效前平台依据已经发布的其他规则、办法等给予商户的处罚不受影响。
2、为了保证商户的权益，我们对每一个商户的处罚都非常谨慎，经过多重人工确认，尽力避免对商户的误处罚。但由于违规行为的类型和表现形式繁多，人工和或系统排查的准确率受到客观因素和技术发展水平的限制，在极端偶然情况下，如因上述情况影响造成对商户的误处罚，商户同意予以谅解并不予向平台追究因此造成的相关损失，平台将尽可能将因此造成的不利影响减少到最低程度。
3、本管理规范首次发布日期为2024年6月28日，自发布之日起7日后生效。
