# 图谱维护与路径循迹：本轮交付与使用说明

## 范围

落实用户确认的模块 1—4 的第一轮交互改进：本体画布、知识台账属性编辑、主图谱拖动和局部路径循迹。实体/关系已有结构化编辑与修订同步机制，继续复用。本轮没有修改自然语言查询、OAG、适用范围语义、数据库迁移、投影同步或后端读写接口；另一聊天仍在调整这些能力。

## 主知识图谱

- 拖动节点调整本次浏览位置；拖空白平移；滚轮及加减按钮缩放。拖动不触发节点详情。
- “适应画布”恢复可见视图，保留节点坐标；“重新布局”重新排列节点。节点拖动和布局不写知识修订。
- 同范围刷新保持屏幕位置和缩放；同项目切换类型视图时保留已有节点位置；清理工作区或切换项目会清理视图会话。
- 圆形节点使用等比例坐标变换；拖最外侧节点时，松手不自动缩放全图。路径面板展开造成尺寸变化时，画布跟随调整。
- 保留既有节点/关系详情、原文依据、编辑、修订历史、台账定位及版本绑定。

## 路径循迹

1. 展开画布下方“路径循迹 · 当前已加载图谱”。
2. 选择起点、终点；或先点击实体，在详情中点“设为路径起点/终点”。同名实体在选项中附编号以区分。
3. 选择按关系箭头或忽略方向，以及最大跳数，点击“寻找路径”。
4. 画布突出显示一条按关系边数最短的路径；链条中的实体和关系可以点击，查看既有详情/原文/版本。
5. 忽略方向时，反向经过的步骤明确标注；原始事实方向不改变。
6. 修改条件、图谱范围、关系端点或修订后，旧结果清理；“清除路径”恢复常规图谱展示。

路径只搜索**当前画布显示的已加载实体和正式关系**，排除虚拟属性值节点与边。它不是全库寻路，不加载额外事实，也不构成规则证明或因果推断。无路径提示只适用于当前方向、跳数和已加载范围。全库寻路需等另一聊天的统一范围/投影能力稳定后单独接入后端，避免提前实现不一致的过滤。

## 知识台账

切到属性视角，点“编辑”可使用结构化表单修改显示文本、属性类型、所属实体、值、数据类型和业务时间。类型取自记录绑定的本体发布；原主体不在当前加载列表时会保留并提示。实体选项只读取当前查询范围最多 1000 条，界面如实披露该限制。

保存复用既有记录修订接口，传原 expected_version 并保留本体绑定和其他可写字段。保存成功更新修订号和相关视图；重复点击、过期项目/范围响应、服务端错误都不会静默覆盖。高级 JSON 仍保留。

后端目前接受字符串、布尔、整数、双精度四种原始值。表单的日期、日期时间及 JSON 模式提供格式校验，仍以字符串保存，不宣称新增了原生日期/对象型后端能力。业务失效时间必须晚于生效时间。

## 本体画布

现有选择、两步连关系、改父类、草案和发布流程保留。补充常驻手势说明及单独重新布局按钮。拖动节点不误选、不推进连线操作；新增元素、重复选同一视图时保留现有位置和视口；层带随节点移动。移动布局不产生本体命令，换项目重新初始化交互会话。

- Node 前端测试：`node --test tests/service/*.test.cjs`，本轮验证 107 项通过，其中新增 28 项行为测试。
- 真实 Edge/Chromium：运行 `D:/anaconda/envs/llm_model/python.exe scripts/verify_graph_maintenance_browser.py`。使用真实静态页面、ECharts/Cytoscape 与被拦截的 API fixture；验证资源存在/加载顺序、节点拖动、松手/刷新屏幕坐标保持、平移、缩放、适应/重新布局、路径高亮/关系详情、同 ID 端点变化失效、属性保存及本体画布拖动/增量保留。
- 浏览器证据保存在 `.benchmarks/graph-maintenance/`（结果 JSON 与截图）。该目录是本地验证产物，不是业务数据。
- 浏览器中的属性保存仅更新内存 fixture；没有写业务数据库、调用 LLM 或重启共享服务。没有运行 PostgreSQL pytest，避免与另一聊天正在进行的数据库验证冲突。
- 这不是生产库全链路验收或后端 OAG 完成证明。实际数据联调需在相关迁移和后端改动收尾后再串行验证。
