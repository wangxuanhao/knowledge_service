## 存储与模型

- MinIO 保存原始 ZIP 及其中实际引用的图片、视频。ZIP 内的 MD 原始字节保留在原包中，来源接口按文档提供下载。单独上传的视频保存为原件。
- PostgreSQL 保存来源版本、metadata、解析块、OCR/ASR 运行与文字片段、切片映射、本体、正式事实和来源断言。
- Milvus 保存检索投影，包括关键词和向量索引。
- ASR 采用本地 SenseVoiceSmall、FSMN-VAD 与 FunASR 1.3.22，CPU 双线程，在禁网子进程中运行，结束后释放模型内存。模型目录及参数见 `.env.example`。

本轮 OCR 测试图识别出 3 个文字块，平均置信度约 96.4%。ASR 识别结果为“欢迎大家来到摩哒社区进行体验。”，语音段为 750–4520 毫秒，样本中的“魔搭”出现误识别。独立适配器调用用时约 83.5 秒，页面正式上传任务中的 ASR 运行用时约 190.9 秒，均包含模型启动和识别过程。

首期视频限制为 25 MB、600 秒。MP4 使用 H.264/AAC，WebM 使用 VP8、VP9、AV1 与 Opus/Vorbis。远程视频引用显示待固化状态，离线处理使用包内本地视频。天猫样本链接的 HEAD 请求返回 HTTP 490，本轮 ASR 验收使用上述本地测试视频。

## 修复与兼容

- 修复证据路由误传服务对象导致的 HTTP 500，通过应用数据接口调用固定来源解析。
- 发现模式的新候选和断言保存正文哈希及来源收据版本。此前生成的记录通过固定正文、切片范围、精确引用及 MinIO 原包独立核验，证据中保留实际的哈希保存状态。
- 修复 ASR 精确证据落在第二段时跳到第一段的问题，按裁剪后的语音段重算时间。
- 独立视频使用内部引用关联媒体，支持包含 `#`、`%?` 及中文的原始文件名。
- 无语音资料可保留原件和处理提示，完成零切片的文档处理。
- 修复原文初始加载期间点击解析标签丢失的问题，标签在当前来源处理函数就绪后启用。
