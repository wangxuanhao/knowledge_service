主权重分别为 936,291,369 和 1,721,366 字节。迁移配置、词表、示例及隐藏元数据，不能仅移动权重文件。主仓库和现有统一媒体 worktree 的本机配置均已指向上述项目路径；该 worktree 的 `data/model` 原本通过目录联接共享主仓库模型，不应递归删除。

组合适合目前离线视频转文字需求。冷启动模型有明显耗时，当前短视频验收不能代表实时转写、长视频吞吐或平台规则专业术语准确率；这些需要单独语料测试。图像继续走 OCR，视频不做帧 OCR。

## 校验与离线验收

源目录位于 `C:\Users\Thinkpad\.cache\modelscope\hub\models\iic` 下上述两个模型目录。项目内副本的全部 32 个文件已与源文件逐个核对字节数和 SHA256，清单保存在本机 `.benchmarks/asr-model-migration-20261112/model-copy.json`。

C 盘旧副本目前保留在原父目录下的 `SenseVoiceSmall.migration-backup-20261112` 和 `speech_fsmn_vad_zh-cn-16k-common-pytorch.migration-backup-20261112`。自动审批拒绝了删除操作，仅返回“策略拦截”，因此没有删除或声称释放空间。这两份备份共 944,051,950 字节；运行配置已切换到 D 盘，不再使用它们。

验收输出、运行日志和路径切换记录保存在 `.benchmarks/asr-model-migration-20261112/`，属于本机运行证据，不随 Git 分发。主服务地址为 `http://127.0.0.1:8100`。路径修改后需重启；`/api/ingest/capabilities` 的 `asr_available` 仅表示依赖和配置可用，仍应通过含语音视频检验转写。
