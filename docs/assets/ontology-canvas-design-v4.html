本体三维：类（父子继承）· 关系（domain→range）· 属性（类的字段 + 数据类型）。 知识写入两条路：① 上传原文（.txt/.md/.pdf/.docx 解析抽取，后台任务，结果回来落到候选列表）② 自然语言（AI 即时抽取）。 两条路抽出的新概念都进右侧候选列表，「收下」后画到画布虚线节点，一起走「校验并审核 → 发布」。
属性校验的口径：属性的 domain 是类（挂在哪个类上）、range 是字面量数据类型（string/int/float/date/bool，不是类）。 所以「属性」与「关系」在机器校验时不同：关系查「两端是不是合法类」，属性查「值的数据类型对不对 + 挂在哪个类上」。
