1. token 级流式做不到 —— 抽取是结构化 JSON（generate_typed），要拼完整才校验；你要的「分析师一步步说」是阶段流式，够用但别期待逐字出。

3. 「后端状态机 7→2」放最后 —— 先复用现有 draft API 把 UI 合了，最后再删门禁死代码，避免「UI 合了、门禁还在打架」。
