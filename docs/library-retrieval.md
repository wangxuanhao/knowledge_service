# 资料库检索范围

资料库提供关键词、向量检索、混合检索三种方式。

- 关键词：在当前资料范围内检索名称、文件名与正文，支持目录分页。
- 向量检索：使用切片向量召回资料。每个切片的索引文本携带所属文档的标题／文件名以及切片正文，因此标题和文件名也参与语义检索。文档正文通过切片进入索引。
- 混合检索：针对同一查询同时使用 Milvus 的 BM25 关键词召回和稠密向量召回，再用 RRF 合并排名。资料范围需要资格分批时，两路先各自汇总全局候选，再进行一次融合，避免把批内排名当成全局排名。按匹配切片归并为资料，展示正文摘要。

向量与混合检索使用当前已构建并同步的索引，不把“已上传”当作“已可检索”。文档标题或源文件名修订后会触发相关切片重新投影；同步完成后使用新标题。当前实现沿用有界召回，最多处理 100 个匹配切片，页面明确显示“本次召回”，不将其计数表述为全库精确总量。模型或索引不可用时明确报错，不静默切换为关键词查询。

“混合检索”与“在结果中继续检索”含义不同：前者融合关键词与语义排名；后者按用户指定顺序逐步缩小资料范围。递进条件可以包含关键词、向量或混合模式，每步保留项目、业务范围等过滤条件；清空、分页、返回上一步和刷新都保持当前模式的正确语义。

API：`POST /api/projects/{p}/sources?query=退款到账&retrieval_mode=hybrid`。请求体沿用资料库范围对象；`search_steps` 的 `retrieval_mode` 也支持 `keyword`、`semantic`、`hybrid`。返回的 `search_mode` 与本次查询一致，游标绑定查询模式，不能跨模式复用。
