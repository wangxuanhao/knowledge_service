# 资料库检索范围

资料库提供关键词、向量检索、混合检索三种方式。

页面将两种混合策略命名为“限定关键词范围”（keyword_rerank）和“扩展相近含义”（fusion），选择后就地说明差异及退款示例。

结果解释区分检索方式与实际出现的文字。关键词目录返回标题、文件名、正文、编号或别名的命中字段，正文只传输命中附近的有界摘要。语义及混合结果显示实际召回通道与相关切片，整段摘要不作关键词标黄；即使标题含查询文字，也不代表向量分数可归因给标题。标题、文件名与片段使用同一向量，不能给出各自贡献百分比。黄色只标记关键词查询的实际文字；语义片段的原文入口使用块级定位，保留精确证据引用原有的逐字高亮。

- 关键词：在当前资料范围内检索名称、文件名与正文，支持目录分页。
- 向量检索：使用切片向量召回资料。每个切片的索引文本携带所属文档的标题／文件名以及切片正文，因此标题和文件名也参与语义检索。文档正文通过切片进入索引。
- 混合检索有两种明确策略。`keyword_rerank` 先以 BM25 分词命中形成候选，再只在候选中按向量相似度排序；不会加入纯语义命中的其他资料，也不允许本体扩展补召回绕过关键词边界。`fusion` 针对同一查询同时使用 BM25 与稠密向量召回，再用 RRF 合并排名；资格分批时，两路先各自汇总全局候选，再进行一次融合。两种策略都按匹配切片归并为资料，展示正文摘要。

页面默认使用 `hybrid_strategy=keyword_rerank`；兼容 API 默认 `fusion`。最低语义相似度 `min_semantic_score` 默认 0.35，可在资料库、图谱、问答的检索设置中调整，支持 -1 到 1。它是余弦相似度，不是命中概率；应结合实际模型和业务查询调整。纯语义检索及关键词候选的语义排序仅返回达到阈值的内容；融合策略在融合前过滤语义一路，关键词一路的有效命中仍可保留。

未设置阈值的向量 top-k 不会直接返回全库，但会尽量取最相近的若干条，即使这些内容仍不相关。关键词候选语义排序每个资格批次最多取 1000 条 BM25 候选，属于有界检索；资格分批的候选最后按全局可比的余弦分数排序。关键词匹配不等于整段查询逐字匹配，BM25 使用中文分词。

向量与混合检索使用当前已构建并同步的索引，不把“已上传”当作“已可检索”。文档标题或源文件名修订后会触发相关切片重新投影；同步完成后使用新标题。当前实现沿用有界召回，最多处理 100 个匹配切片，页面明确显示“本次召回”，不将其计数表述为全库精确总量。模型或索引不可用时明确报错，不静默切换为关键词查询。

“混合检索”与“在结果中继续检索”含义不同：前者融合关键词与语义排名；后者按用户指定顺序逐步缩小资料范围。递进条件可以包含关键词、向量或混合模式，每步保留项目、业务范围等过滤条件；清空、分页、返回上一步和刷新都保持当前模式的正确语义。

API：`POST /api/projects/{p}/sources?query=退款到账&retrieval_mode=hybrid`。请求体沿用资料库范围对象；`search_steps` 的 `retrieval_mode` 也支持 `keyword`、`semantic`、`hybrid`。返回的 `search_mode` 与本次查询一致，游标绑定查询模式，不能跨模式复用。
