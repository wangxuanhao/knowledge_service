## 架构与存储决定

- PostgreSQL 保持项目、本体、事实、来源、双时态修订与审计的权威存储。
- 模型生成 embedding；Milvus 是唯一向量存储、索引与向量召回后端。不可用、维度/模型身份不一致、投影未就绪时明确失败，不自动换关键词或本地向量。
- 关键词检索是用户明确选择的独立策略。可选 Neo4j 只作可重建图投影，不能代替权威事实、权限、时间与范围判断。
- 新增 SQL 范围读模型、keyset 分页和精确 ID 批读；本体/内容范围先资格过滤。图会话检查项目水位避免旧清单在知识变化后继续泄露。
- 迁移 0020 增加 current kind/keyset 及 subject/object 邻接索引；不改历史 payload 字节、不修改既有迁移、不另造实体权威。
- 真实 150k/300k 数据核验暴露端点资格估算错误（估计 2 行、实际 150k 行）及重复 JSON 解析瓶颈；0021 已增加由原 payload 自动生成的读取列和索引。原业务库已通过常规迁移器应用 0020/0021，当前 schema 21；没有修改旧迁移或原始 payload。
- 同负载、VACUUM 后的成对执行计划检查中，10001 条关系页从 13.784 秒降至 1.581 秒；保留关联子查询的分页扫描避免每页扫描/排序全部 300k 关系。此为单对查询检查，不是端到端 P95。详见[计划与测量](2026-10-19-scoped-read-query-plan.json)。
- 大规模 Milvus 写入暴露了 Windows bind I/O 导致 etcd 会话超时、Milvus 退出码 80。已配置 60 秒会话 TTL、明确内存上限，并完成四个 Docker 数据目录到 Linux 命名卷的停机复制。源目录仍保留；文件内容及约定元数据校验一致，恢复后四服务健康、初始重启数均为 0。协调者独立比对迁移前后快照，两个数据库的表/迁移记录完全一致，27 个 Milvus 集合及逻辑数量完全一致。详见[公开迁移审计](2026-10-19-docker-storage-migration.json)与[迁移指南](../2026-10-19-Docker-Linux-volume-migration.md)。迁移后的 450k 逻辑投影与后端容量重测通过；产品页面和最终完整回归已另有独立结果，见本文件相关章节。
- 浏览器实体进入紧凑 GPU 缓冲；全部关系先绘入完整世界坐标缓存，平移缩放复用该关系层，实际实体点仍逐帧绘制。标签数量独立于实体集合。

## 产品端容量复核与性能修复

真实 HTTP 路径最终长测的暖态 semantic / hybrid P95 为 1.031s / 1.484s，包含查询编码，四并发请求也完成原生 Milvus 召回。历史首轮真实产品全图完整加载并绘制 150k/300k，唯一 ID、清单、端点和 GL 状态全部正确，但总计 127.89s，**未达到 30s 目标**。该轮已停止，未把完整计数改写成性能通过。

边界探针复现总计 121.219s：30 个实体页服务等待共 14.927s、60 个关系页共 98.547s；传输约 1.44s、renderer sync 2.026s、Worker layout 0.329s。两个关系请求分别等待 33.844s、27.866s。独立 HTTP 对照再次出现两个约 33.25s 的慢窗，相隔 60.412s；慢窗 SQL 指纹与后台 `current_records` 的全载荷读取精确一致，实际 Scope DTO 与空范围的 SQL/参数相同，5k/10k 页均保持 keyset 计划。

根因是每 60s 的投影审计在共享仓储快照锁内读取并重建 450k 全量载荷，阻塞前台分页。已改为独立只读快照和紧凑权威清单、按捕获版本每批最多 256 条读取修复载荷，保留审计、水位与租约复核。新增 6 项回归先观察失败，修复后审计/runtime/authority-bundle 合计 20 项通过；真实 450k 清单读取 2.51–2.83s，期间主仓储完成 69/77 次读取，最大延迟 0.203s。诊断证据见[公开记录](2026-10-19-product-graph-latency-diagnosis.json)。

紧凑图分页另避免再次经过 FastAPI 的通用 Python 对象遍历；针对 5k 行响应的回归先失败、修复后通过。投影边界/传输聚焦 12 项通过：陈旧向量索引明确失败，显式 keyword 保留重新资格过滤和准确 ID 范围的独立测试，没有恢复本地向量替代。

重启真实服务后，相同浏览器路径完整加载并绘制 150k/300k 为 17.781s，无页面错误；实体 30 页服务等待共 4.036s、关系 60 页共 9.483s，未再出现约 33s 停顿。这是单轮边界探针，不能替代后续固定五轮分布。

[真实产品长测](2026-10-19-product-capacity-validation.json)已完成。该轮与独立数据库的完整/聚焦回归共享宿主资源：固定五轮完整加载为 46.906 / 34.156 / 39.812 / 30.563 / 28.344s，完整 P50 34.156s、P95 46.906s，**30s 目标未通过**；首次可见 P95 1.585s。稳定阶段实际经过 1871.141s、72 次真实指针平移缩放采样，包含局部/全量、项目 A/B/A、本体范围 A/B/A 切换，交互帧间隔 P95 最大为 16.8ms，未丢失上下文或出现脚本错误。浏览器进程 RSS 峰值约 2.786 GiB，未超过预设 3 GiB；共享详情实际点击反馈 P95 为 188ms。含编码的 HTTP 暖态 semantic / hybrid P95 为 1.031s / 1.484s，均保持原生 Milvus。
