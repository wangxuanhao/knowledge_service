# 资料库与文件/记录抽屉修正验收

日期：2026-10-20。范围：资料列表、资料详情、文件上传、批次入口、结构化导入和新增实体/关系/属性的展示与生命周期保护。沿用现有后端、鉴权、解析与 Milvus 协议。

## 交付行为

- 资料列表占满主内容区，初次读取、刷新和筛选不再自动打开第一篇原文；点行才打开右侧详情。
- 原文、提取知识、处理记录、修订记录集中在资料详情抽屉。关闭恢复列表焦点；异步读取按文档/页签/请求序号/项目与范围校验，关闭后返回的请求不会覆盖重开的详情。
- 添加文件在右侧抽屉内分三个步骤；保留原始输入节点、文件队列、既有处理模式和服务端提交。元数据和高级解析参数默认折叠。
- 上传成功后切至处理批次；收起抽屉不会取消任务。结构化导入是独立抽屉视图，原整批校验契约不变。
- 台账新增实体/关系/属性使用靠右表单。正常导航和程序直接切项目均关闭旧表单；未提交文件/资料信息不带入新项目。
- 切片预览在 native dialog 内可交互；关闭/切项目清理 inert 与滚动锁；延迟预览不会重新锁住背景。原文阅读器与抽取结果通过先关闭主抽屉的方式交接。
- 重试入口先进入确认步骤，避免绕过最终提交；旧项目批次不能修改新队列 session、覆盖新提示或重新弹窗。完成的旧批次卡片也会在直接切项目时隐藏，写动作复核所属项目。

## 边界

当前文件表单仍采用本批共用的范围、时间及 Metadata，多文件以各文件名为标题，不宣称已有逐文件覆盖。当前本体“待建模”新流程仍是单独设计提案，本次未将其伪装为已接入服务。容量目标与性能结论沿用独立诊断，抽屉改造不构成大库性能达标证明。
