# 检索与图谱渐进交互验收（2026-10-20）

已集成到主项目，使用正常 `python -u -m knowledge_service --port 8100` 启动。保留容量项目与 Milvus 投影未重建，未重跑数据迁移或种子脚本。本次只创建读取图谱所需的会话，不修改测试语料。

## 实际修改

- 图谱设置改为右侧原生抽屉。关闭按钮、Esc、遮罩均可关闭并恢复焦点；切项目、切页面及进入全量模式清理对应抽屉。
- 图谱、脑图分别保留查询与候选结果，均有首页、上一页、下一页和页数。服务端按页读取 50 条；搜索期间禁用旧分页，选定实体保留，别名命中不会被前端二次过滤隐藏。
- 局部扩展可填写 0–10 整数。前后端严格验证，不再截成 3 跳或把 0 变成 1；方向、实体和关系预算继续有效。
- 详情“展开脑图”按准确实体 ID 和已应用的检索页时间、Metadata、本体范围核验，不依赖候选列表当前页。请求有项目、范围代次及根实体代次守卫。
- 脑图服务从旧全库扫描改为有界邻域读取：深度 0–5，最多 500 实体 / 1000 关系；树最多 500 项，每分支最多 40 子项。循环与截断有明确状态。
- 全量模式先加载 400 条关系及同范围端点，自动暂停。下一批、自动继续、本批后暂停、取消和重新开始均可用。先枚举关系，再扫描实体以覆盖孤立实体；两路穷尽且精确计数匹配后才能显示完成。
- 连接页同一读取快照内检查会话所属账号、项目、范围、水位与端点资格。游标绑定会话与数据种类；过期或水位失效要求重新开始。
- 关系线修复包括透明度混合、稀疏图直接画线、密集缓存缩小采样及缓存增量更新。小图（≤800 实体）常规缩放显示最多 50 个避让标签及更大的节点；密集图保留有界标签路径。标签多少不改变实际加载数量。
