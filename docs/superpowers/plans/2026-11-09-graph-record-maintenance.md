# 图谱与台账维护体验实施计划

用户已确认补充图谱新增实体入口、统一知识变更刷新和基础视觉规则。后续补充要求是去除类型区嵌套滚动，并完整显示检索方式。

## 实现边界

- 正式创建、修订、删除、融合和撤销继续使用现有服务及权限、本体、并发版本校验。
- 使用一个知识变更协调入口通知台账和图谱。保存成功与刷新失败分别反馈，跨项目的迟到响应不得改动画布。
- 局部图保持起点、当前跳数和筛选。重新核对已展开分支，并遵守总实体、关系和属性预算。
- 全量图在同一范围重建有界会话，保持模式、类型筛选与视角。首次最多读取当前默认小图预算，大图由用户继续加载。
- 图谱新增实体复用现有表单。历史范围只读，创建成功提供在台账查看入口。
- 共享颜色、线条与选中规则。大图继续使用有界标签和轻量绘制。
- 类型筛选采用紧凑入口与可展开列表，保持所有类型可访问。检索方式留足文字和原生箭头空间。
