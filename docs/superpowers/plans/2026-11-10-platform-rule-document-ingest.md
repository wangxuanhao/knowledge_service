# 平台规则文档时间接入与图文上传实施计划

> 执行采用 subagent-driven-development，按任务进行需求与质量复核。

**Goal** 从每份规则正文识别资料发布时间与业务有效期，写入现有规范字段并保留证据，复用全部历史及时间筛选。核实 Markdown 与相对图片附件的现有上传能力，交付可操作的打包规范。

**Architecture** 文档时间解析集中在一个服务模块，统一在文档摄取入口应用。新增显式自动识别模式，现有调用保留手工模式兼容行为。现有 PostgreSQL、来源版本、ZIP 包读取与图文阅读链路继续承担存储和展示职责。

**Tech Stack** Python 3.12、Pydantic、现有 FastAPI/PostgreSQL、原生 JavaScript、pytest 和 node:test。

## 已确认的业务范围

- 默认展示全部历史，保留现行、失效、未来和未知时间资料。
- 发布时间写入 metadata.published_at，生效与失效写入 valid_from、valid_until。
- metadata.document_temporal 记录逐字段候选、日期原文、字符位置、时区、确认状态和冲突。日期缺失保持未知。
- 自动识别优先覆盖明确字段、标题明确失效标记及文档自身施行/废止语句。专业条款期限、引用规则、公告目标规则的时间需要保留正确归属，歧义进入待核验。
- 中文无时区日期按 Asia/Shanghai 解释，再存为 UTC。明确有效至某日的结束日转换为次日零点，明确某日起失效使用当日零点。
- 同一文档的首次生效、修订日期与当前版本生效分别识别。选择当前版本的明确生效表述，互相矛盾的候选待核验。
- 上传手工给出的具体字段优先。自动模式仅有发布时间时，业务生效保持未知。手工模式继续兼容既有发布时间推定行为。
- 新设置 document_time_mode 取 auto/manual，API 默认 manual 保持兼容，上传界面明确提交 auto。自动模式校验阶段跳过发布日期回退，从而保留原始字段是否明确提供的区别。
- 自动候选构成反向区间时，保留候选并转待核验。某一边界为手工值时保留手工值，将冲突的自动边界保留未知。两个手工值仍沿用现有输入校验。
- 日期位置以本次分析的规范化搜索正文为坐标，保存分析文本 SHA-256、解析器版本和 coordinate_basis。来源版本单独关联，OCR追加文本通过既有来源片段映射定位。重试验证同一原文得到相同结果。
- 上传预演、处理后摘要和重新打开详情时，auto 模式只有发布时间的资料均显示生效未知，逐份时间结果与正文依据一起可读。
- 单文件、多文件、ZIP、粘贴正文、同步与队列处理统一进入同一时间解析逻辑。重试保留相同解析依据。
- 平台原始“是否生效”单独存为来源状态，日期未知和状态冲突显式提示。本次验证已有日期过滤；完整原始状态历史推理另行列出边界。
- Markdown 图片包保持原目录关系，图片固化到现有来源对象存储，阅读使用来源版本与鉴权资产接口。

**命令行契约**

```powershell
python scripts/package_rule_documents.py --root "D:\workspace\知识图谱源数据\平台经济规则" --list-file selected.txt --output-dir packages
```

- 选件支持重复的 --file、UTF-8/UTF-8-BOM 逐行路径清单 --list-file，以及现有 documents/path/title/metadata 格式的 --manifest。路径均相对 --root，去重并保留选择顺序。JSON 清单保留显式 title/metadata。
- 使用现有 parse_markdown 识别标准 MD、HTML img、引用式图片，支持中文、空格、URL 编码和合法的父级相对图片路径。只打包选中文件及引用附件，MD 字节与路径保持一致。相同图片在单包去重。
- 本地缺图、格式不支持、越出根目录、符号链接或非法路径应失败并给出文档和路径。外链图片记录警告并保留 URL，内嵌图片保留原文。统一通过现有 MarkdownPackageReader 校验每个成包。
- 默认每包最多 200 份 MD，ZIP 体积最多 24,000,000 字节，可通过 --max-documents 和 --max-zip-bytes 降低限额，参数不得超过服务默认上限。另遵守 5000 成员、512 MiB 解压和正文限制。选择较多文件时自动分包，单份资料及图片超过上限时给出错误。
- 每包生成 manifest.json。输出独立 packaging-report.json，包含每包文档、图片、大小、SHA256、外链警告与源文件核对信息。以暂存目录完成全部打包与校验后发布到新输出目录，已有目录拒绝覆盖，失败时不留下可误传的半成品 ZIP。
- 脚本运行沿用已有 Python 环境与仓库依赖，操作采集文件为只读，打包使用 ZIP_STORED 保证可预测的体积及压缩比。
