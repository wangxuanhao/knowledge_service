# 自动检索索引与检索策略实施计划

目标：用户确认开始解析后计算切片向量，正式提交后自动建立或更新检索索引；草稿始终不能参与正式搜索。保留 PostgreSQL 权威数据、Milvus 派生索引、现有投影租约与代际切换。

- [x] 为文档编码添加按模型、维度、完整索引文本寻址的有界磁盘缓存，解析后预计算，正式投影复用；缓存不存 PostgreSQL，不作为可检索记录。
- [x] 后台首次构建与故障恢复复用现有重建任务，指数退避、避免重复提交；写入只唤醒后台，不同步执行编码。本体发布同步使用当前投影版本并覆盖属性。
- [x] 在资料库、图谱、问答提供统一“检索索引”入口，展示自动更新、进度、错误及手动重建；区分预计算和正式索引可用。
- [x] 混合策略提供关键词候选语义排序及双路融合，增加 0.35 默认语义最低相似度（可调，余弦值不是置信概率）。关键词命中不受双路融合的语义阈值影响；纯向量只返回达到阈值的 top-k。
- [x] 对缓存失效/失败、后台重试与去重、候选资格、阈值在融合前应用、草稿隔离执行回归；运行相关 Python 与 Node 检查及真实服务验收。

接口兼容：仍使用 keyword / semantic / hybrid 三种模式；hybrid_strategy=keyword_rerank 或 fusion，API 默认 fusion，页面默认关键词候选语义排序。资料库递进条件保留每步策略与阈值；旧请求沿用兼容默认值。BM25 候选每批最多 1000 条，结果为有界召回而非全库精确总量。

验收：154 项相关 Python/浏览器回归、1 项独立历史同步恢复回归、1156 项 Node 契约通过。真实 Milvus 分组检索验证关键词、向量、两种混合策略及阈值空结果；本地 4 个项目自动重建就绪，两条旧 watermark 失败的本体同步任务恢复完成。
