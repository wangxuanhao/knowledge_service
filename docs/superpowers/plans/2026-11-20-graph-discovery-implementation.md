# 图谱筛查与社区检索实施计划

**目标**　从确定实体出发反复筛查有向邻域，并对同一项目的已治理图谱浏览社区和生成有出处的跨社区回答。

**边界**　沿用 FastAPI、PostgreSQL、持久后台任务、原生工作台和来源检查器。社区报告按构建范围引用正式事实。图谱筛查在服务端应用约束，可回退或从命中的节点继续展开。

- [x] 在 `api/graph_sessions.py` 和 `services/graph_workspace.py` 接入邻域条件链。先验证沿途关系、方向、跳数、来源日期和截断区分，再接通筛查路径与证据。
- [x] 在 `api/communities.py` 和社区服务中接入聚类、报告、构建状态和问答。验证同范围去重、跨范围隔离、稀疏覆盖、模型错误恢复和引用。
- [x] 在 `web/` 接入邻域筛查、社区浏览、构建管理和社区问答。验证条件与范围在请求、撤回和导航后保持一致。
- [x] 在隔离 PostgreSQL 验证路由、迁移与状态。在 Edge 验证图谱和社区入口、结果列表、证据及重试。运行前端契约测试和相邻检索回归。
