# 检索、脑图与渐进大图修正

用户要求：设置可正常关闭；实体选择分页顺手；跳数可填写；实体详情“展开脑图”不能误报无实体；大图应先显示局部及关系，再逐步完整，不要求等全库后才可用。

## 本轮行为

- 图谱设置用页面右侧抽屉承载，显式关闭、Escape/遮罩关闭及焦点返回；主画布不被向上撑开。沿用当前设置字段与显示模式。
- 实体选择支持名称/ID 搜索、上一页/下一页、当前页与总数；图谱和脑图各自保留搜索/分页状态。选中实体不因翻页失效，精确 ID 入口仍校验真实范围。
- 局部邻域跳数改为整数输入，支持 0–10 跳；前后端一致校验，不再静默压成三跳。仍受明确的节点/关系预算约束，截断如实展示。该范围仅改变图谱邻域，不混改问答推理的独立参数。
- 从实体详情展开脑图时携带真实实体 ID 与当前已应用的项目/本体/时间/Metadata 范围；不依赖该实体是否恰好出现在选择器当前页。先确认根实体可用再生成；异步切项目/范围/根节点不会落地旧图。
- 大图先读取少量关系及同会话内经过资格校验的端点，第一批就能显示连线；每批同步渲染。初始批次后暂停，提供“下一批”“自动继续”“暂停/继续”“重新开始”，已画内容继续可平移/缩放/查看。自动继续最终包含全部关系及孤立实体，核对清单才标完整。
- 暂停保留同一会话和游标；取消或项目/范围变化中止请求，不能混入旧批次。水位变化或过期明确提示重新开始，不偷偷换新快照。
- 修正关系图层的 alpha 合成并用像素/绘图断言验证可见线，不能只检查关系计数。大图保留显示线、定位、真实详情、来源与编辑入口；数量与当前完整性可见。

## 验证与边界

先用小而确定的回归复现三跳截断、未加载选项的脑图跳转、只有下一页以及实体先全读的加载顺序；再修正并运行前端/相关后端检查。真实主应用保留的 150001 实体/300000 关系项目验证第一批同时有节点与关系、暂停/续载、绘图像素、取消/范围失效。完整 150k 终态仍需核对计数，不用小图代替大库容量证明。

数据库、版本/来源资格、会话归属、Milvus 唯一向量路径保持既有约束。不得重置或重新造容量数据，也不通过本地向量/关键词降级掩盖错误。
