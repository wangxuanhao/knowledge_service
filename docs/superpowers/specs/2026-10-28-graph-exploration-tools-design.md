# 图谱探索工具：邻居、分支与静态聚焦

用户于 2026-10-28 批准按 Semantica 第一轮建议规划后实施，要求保留其他能力和纯 CPU 性能。

## 范围

- 共用一个“邻居”工具入口和轻量面板。展示当前画布选中实体的直接关系、方向、邻居类型与名称，按页显示，点击定位并打开既有详情。明确是当前已加载图的关联，未显示不表示全库不存在。
- 局部图支持保留当前图的分支扩展和收起。初始图作为固定基础；展开结果归属于发起实体，收起撤回该分支独有的呈现，其他分支共享实体/关系及基础图保留。无可见锚点的后代分支一并隐藏。再次展开可重新获取，不改知识存储。
- 静态聚焦提供 1 / 2 跳及方向控制，默认 1 跳、双向；有数量和扫描预算，超限明确提示。聚焦节点/边正常显示，其他淡化，退出恢复原画面。名称关闭时不因聚焦重新出现。
- 全量图在持续追加时仍可浏览邻居和聚焦，数据全集及 manifest 计数不变。全量图分支展开使用既有局部探索路径，明确切换，不能将后端邻域混入已冻结的全量会话。
- 分支可见性从基础节点求固定点；无基础支持的分支环不能自我保活。收起递增分支票据，等待中的同锚点响应必须丢弃，避免复活已收起分支。
- 邻居和聚焦只读取实际显示的类型投影；不得经隐藏类型绕行得到二跳关系，也不得将原数据下标用作投影坐标。

## 模块与边界

- 新 `graph-exploration.js` 为纯模型：增量邻接索引、分页、有限 BFS、局部分支归属与预算，不依赖 DOM，不复制全量记录。
- 新 `graph-explorer.js` / `.css` 为工具和面板，消费局部与全量适配器；面板关闭不改变图数据，不增加持续计时器。使用 textContent 渲染用户数据。
- `workspace.js` 在既有范围票据保护之后接受分支响应，保留初始绘制/刷新含义；展开按钮及邻居面板走新扩展入口。项目、时间、本体、类型范围变化和清空均清除分支与聚焦，迟到响应不能复活分支。
- `GraphWorkbench` 在其既有样式快照上组合聚焦与路径效果，路径强调优先；保持手工坐标和相机。全量 Renderer 复用现有 Canvas2D 标签层画有界聚焦覆盖，将背景 GL 层淡化；常规 GL 绘制/缓存/拾取及加载协议不改。
- 邻接索引以整数位置和 typed arrays 维护入/出链，首次使用工具时才建立；建立后随追加只处理新增边，额外索引约 O(N+E)。无 focus/面板时不遍历邻接表，无每帧全量扫描；聚焦同时返回有限边的原始引用，覆盖层不再扫描全量关系。
- 首次索引按节点/关系批次分段并让出浏览器事件循环，界面显示读取状态；完整索引就绪前不挂入追加的同步路径。并发邻居与聚焦请求共享一次准备，旧范围响应由控制器票据丢弃。

## 回归与验收

- 纯模型：方向、自环、多关系、分页、追加后游标失效、预算、高度节点扫描上限、二跳、有共同后代的分支收起、范围失效与清空。
- 功能：现有缩放、平移、手工拖动、适应、重新布局、类型筛选、实体/关系名称开关、循迹、详情、全屏、渐进加载/暂停/取消继续可用；虚拟属性节点不得成为错误扩展锚点。
- 几何：局部/全量画布同顶同高，面板不推动工具或占用既有画布轨道，窄屏和全屏控件可达。
- 性能：相同软件渲染 flags、数据和画布对比新增索引构建/追加与未启用工具的平移；工具开启后按有界预算测量，记录首开及更新耗时和额外内存。每档设置时间上限，不重复运行已明显失控的重负载。30 万数据集的短测不能替代完整生产验收。

不更换图引擎，不做社区聚类/中心性分析、语义相似度、持续动画或时间播放，不改后端接口/鉴权/存储。
