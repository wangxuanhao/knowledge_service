# 本体属性编辑

用户已确认先补齐本体属性编辑，不扩展外部数据库映射或实体属性值录入。

## 操作与边界

- 选中实体类型后，属性区显示直属属性及其数据类型，提供「添加属性」「关联已有属性」。新增表单默认当前类型，允许选择数据类型和填写说明。
- 关联已有属性采用可搜索的勾选列表，当前直属属性预选。应用时只生成 add_domain/remove_domain 差异；解除归属不删除属性，也不影响其他类型。
- 继承属性另列，显示来源父类，允许跳转到属性定义。继承属性在当前子类不能直接解除；编辑属性定义会影响所有适用类型。
- 属性详情可编辑名称、说明，名称必填，说明可清空（只移除当前语言的说明），继续通过已有选择器编辑所属类型、数据类型。属性 IRI 稳定；英文标签、自定义注解和其他语言注解保留。
- 新增与编辑均使用现有原子命令/batch 与乐观锁，写入草案后审核发布。历史只读；服务端拒绝时保留输入，项目或版本切换后拒绝旧表单提交。

## 实现与验证

新增聚焦属性的前端模块，避免继续扩张本体详情面板。属性摘要返回可编辑文本的精确 RDF 注解，以便客户端生成准确的 remove_annotation/add_annotation 差异，不猜测语言或字面量类型。

对于升级前已发布、摘要尚无注解的本体，当前与历史读取接口从该版本自身的 Turtle 补齐只读文本投影；完整摘要直接复用，不重复解析。读取不回写持久化摘要、不改写历史版本，也不要求重新发布才能编辑已有属性。

验证覆盖新增的预选归属、数据类型和说明，关联差异、继承来源、名称说明替换与清空、失败重试和历史只读。使用 Node 行为测试、Python RDF 重放测试和真实浏览器桌面/窄屏操作；同步更新资源缓存版本。
