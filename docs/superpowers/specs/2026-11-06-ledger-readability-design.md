# 知识台账布局与可读性

用户已批准：保留表格，优化布局、对齐和长文本。沿用现有浅青主题、原生 JS/CSS 和服务端分页。

## 设计

- 统计、页签、维护入口、查询工具栏使用一致的水平基线；缩减重复留白。
- 表格正文 14px、辅助文字 12px，行高约 1.6。列首行顶端对齐，长标识可换行。
- 六列表格给修订、断言和操作足够宽度；原文片段五列单独分配列宽。窄屏在表格容器内横向滚动，页面本身不溢出。
- 操作按钮保持文字不拆行，使用稳定排列，保留全部既有操作和权限。
- 长实体名、关系上下文、属性值、原文片段默认展示最多三行，通过原生 details 展开全文。全文使用 textContent，保留完整内容，不继续按字符数截断；短内容不重复提供全文。
- 不变更 API、数据含义、过滤、分页或治理规则。

## 验收

在桌面和窄屏核对四种视角：表头与单元格列边界一致、首行顶端对齐、字号可读、按钮不拆字。验证长内容展开后完整且 HTML 样例只作为文字显示。运行现有台账浏览器回归及相关前端契约，并截图检查真实 CSS 级联。
