# 平台 LLM 模型管理

用户已批准保存多套 OpenAI 兼容模型配置并切换全局默认 LLM。

## 行为

超级管理员通过管理导航中的模型管理页面新增和编辑名称、base URL、模型名、API key，测试连接并设置默认模型。列表显示生效状态和密钥是否已设置，不返回密钥。编辑时空密钥保留旧值。连接测试使用真实 chat completions 请求，返回经过过滤的明确结果。

PostgreSQL 保存模型配置和全局选择，默认切换在事务内原子完成。API key 使用 cryptography Fernet 认证加密。独立持久密钥从 KG_LLM_ENCRYPTION_KEY 或受限本地密钥文件读取，丢失或不匹配明确失败。现有 KG_LLM_* 环境配置作为未选择平台模型时的兼容配置。

抽取、问答、属性抽取、本体建议、能力检查、实验指纹使用统一配置解析。每次同步操作和流式问答固定一个不可变配置快照。后台文档执行固定快照，跨线程显式传递，检查点记录模型身份。任务内切换不会混用供应商、模型和密钥。持久任务重试的模型快照用同一密钥加密，公开接口只展示非敏感模型身份。

## 错误与验证

缺配置、非法 URL、密钥不可用、连接测试失败返回可理解的错误。仅超级管理员可读取和修改管理配置，普通管理员和只读角色均被拒绝。外部错误不回显密钥或完整供应商响应。

测试覆盖管理授权、加密存储、编辑保留密钥、默认切换与重开、环境兼容、并发任务隔离、真实入口配置解析、前端交互与资源缓存版本。遵守现有 Python 3.12、PostgreSQL 和原生 JS/CSS 项目约定。
