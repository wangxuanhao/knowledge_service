# 检索与图谱统一工作台

用户已认可整页可交互设计，并要求落到实际页面、增加可收缩菜单、采用一致的线性图标、保留现有全部功能。预览只表达视觉方向，实际页面的功能以当前源码和契约为准。

## 设计

- 采用现有浅青主题：墨青骨架、白色面板、浅青选中态；不引入新的构建系统或外部网络依赖。
- 导航保留全部现有目的地、权限、深链接及原按钮事件；桌面可收缩为图标栏，保留名称提示、键盘操作、当前项与项目切换入口；移动端沿用现有菜单而不是强制图标栏。记住桌面收缩偏好，存储不可用时仍能操作。
- 搜索从拥挤的一行拆成页面标题、完整搜索区、范围摘要。混合/关键词/语义、本体扩展、检索设置、索引入口均保留。
- 范围筛选保留平台/业务/适用对象、Metadata、双时态、原始条件、高级字段与用途兼容提示；使用现有应用/重置逻辑，明确待应用与已应用状态。
- 图谱共用固定模式导航、类型筛选、视图工具与设置入口。保留局部和全量各自渲染及请求状态拥有者，不替换数据模型或伪造功能。
- 图谱设置统一为相同侧面面板外观；保留模式专属选项。局部保留实体选择、方向/跳数/预算、类型/关系和标签开关；全量保留实体/关系定位、显示线与名称。
- 局部/全量共享缩放和适应画布的视觉位置。全量保留首批、下一批、自动继续、暂停、取消、重新开始和不完整/失效状态。
- 检索结果与知识详情/路径沿用现有右侧面板及原节点，保留新增实体、编辑、历史、证据、来源、邻域、路径、时间线和全屏。
- 让常用控件完整可见，窄屏可换行或滚动，面板不溢出，不以隐藏高级功能换取整洁。

## 完整功能基线

1. 应用导航：知识问答、检索与图谱、实体脑图、资料库、知识台账、本体建模、构建与任务、质量评测、项目、人员、按权限显示的模型管理；内部添加文件入口仍注册。
2. 检索：三种方式、本体扩展、索引设置、范围跳转问答、证据结果与知识导航。
3. 范围：适用性、动态字段、Metadata、业务时间/未知时间、系统历史时点、高级 JSON、用途/兼容性与应用/重置。
4. 局部：实体检索选择、跳数、方向、节点和边预算、属性显示、类型/谓词、标签、展开、邻域、路径、时间线、缩放/复位。
5. 全量：渐进加载全部控制、进度/错误/恢复、实体及关系定位、类型分页/过滤、标签/关系线、邻域/路径与缩放。
6. 详情维护：权限及历史只读、增删改、来源、证据、版本、时间范围、外部导航返回。

## 验收

验证新导航行为以及原事件/权限不丢失；完整工作台以实际 HTML/JS/CSS 的浏览器夹具检查两种模式、筛选应用、结果/详情、桌面收缩、窄屏、全屏及关键功能入口。运行 Node 前端契约和相关 Python 浏览器/静态测试，更新变动资源版本。只修改本任务文件，保留正在进行的本体类型修改。
