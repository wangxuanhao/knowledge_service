# 资料库搜索

用户要求直接增加资料库搜索；采用现有目录的服务端关键词查询，名称/原文件名/正文忽略大小写的字面子串匹配，额外保留共用查询已有 ID/别名匹配。保持项目、时间、适用范围和 Metadata 筛选。搜索不是向量语义检索，不依赖模型或 Milvus。

推荐复用 ScopedReads query 参数和分页身份。仅前端筛当前页会漏掉未加载资料；另建语义检索接口则改变目录排序和依赖，均不采用。

API `/api/projects/{p}/sources` 新增 query 查询参数，默认空，最多 2000 字符，去首尾空白。计数统计当前搜索范围内各状态；state 再选择列表子集。metadata-only 返回仍不携带正文，派生知识摘要不受文档搜索词过滤。游标绑定关键词，换词后不能复用旧游标。百分号/下划线等按字面字符串匹配，绑定 SQL 参数。

UI 列表上方有有标签的搜索输入、搜索和清空按钮，Enter 提交，输入法组合阶段不提交。已应用关键词加入加载/缓存身份，分页携带相同词；草稿输入变动不改变已应用结果，提交后重置分页，旧请求不能覆盖。切项目清空搜索；范围/状态/刷新保持已应用词。无结果显示搜索反馈及清空入口。证据来源直接定位应清空资料库搜索再定位，不阻止引用阅读。

测试先行：后端标题/文件名/正文、字面特殊字符、跨页、计数、隔离/历史/筛选、游标换词拒绝、摘要不返回正文；前端提交/清空/状态/分页/慢请求/切项目/证据定位契约。最后真实浏览器 smoke 和服务重启；不改写用户资料，不提交其他任务文件。
