# 技术周报（2026-09-07 ~ 2026-09-11）

**项目**：规则知识图谱平台（本体驱动）
**本周主题**：完成知识图谱项目阶段性搭建，并向中标院进行演示

---

## 一、本周核心进展

本周把知识图谱从"脚本原型"推进为**可演示、可治理的服务化平台**，并完成了对中标院的现场演示。

演示主线是一条完整闭环：

> 原始规则/协议文本 → 本体约束下的 LLM 抽取 → 图谱 + 向量双索引 → 可溯源的证据问答 → 人工审核与版本治理

中标院现场关注的是"规则类知识如何结构化、如何可信、如何追溯"，因此演示重点放在**本体约束抽取**与**带出处的问答**两条能力上，而非单纯的可视化。

## 三、本周建设的能力清单

### 1. 本体驱动（Ontology-first）
- 建立**版本化 OWL/RDFS 本体**：29 个类、24 个对象属性、10 个数据属性、2 个 SHACL 约束。
- **本体维护**：实体类/关系/属性的新增、修改、停用；IRI 稳定不变、显示名可改；每次保存生成新本体版本。
- **SHACL + domain/range 校验**：支持 4 种处理策略（审核/提示/严格/关闭），冲突关系转候选而非静默丢弃。
- **Turtle 高级编辑器** + 结构化表单快捷维护双入口。

### 2. 抽取与知识写入
- **三种抽取模式**：项目本体（闭集受控）/ 开放本体发现 / 仅文档检索。
- **结构感知切片**：固定长度+重叠、段落/句子边界、标题与中文条款（"第X条""一、"）三种策略，切片保留原文字符偏移。
- **LLM 实体/关系抽取**（Semantica + DeepSeek OpenAI 兼容接口），逐片抽取。
- **实体业务属性抽取**（可选）：标量属性 + 原文证据，全部进入审核。
- **消歧与融合**：同名/别名精确匹配 + 语义相似自动合并（阈值可配），合并保留来源。

### 3. 知识审核与本体变更
- **知识审核工作流**：实体/关系/属性/校验四类候选，批准/拒绝均留痕；实体先批、依赖它的关系与属性才可批。
- **本体变更草案**：从审核候选发起，带影响分析（引用数、约束数、风险等级），批准时在同一事务内发布新本体版本并重校验候选。
- **开放本体发现 → 累计草案 → 发布 → 受控重解析**：Semantica 归纳类层次与属性 domain/range，草案复用上一版本稳定 IRI；发布本体与正式实例入图解耦。

### 4. 双时态版本管理
- **业务时间** `valid_from/valid_until` 与**系统时间** `recorded_at/superseded_at` 分离。
- 支持"业务有效时点"与"系统已知时点"两类查询，含 `include_unknown` 控制。
- 乐观并发（`expected_version`），记录全量版本历史。

### 5. 检索与证据问答
- **嵌套 metadata 前置过滤**：9 类操作符、AND/OR 嵌套（深度 16）、点号路径遍历；**在向量排序之前**缩小候选集。
- **语义检索**：FAISS + 本地 BGE-M3（1024 维）向量。
- **证据问答**：实体通道 + 原文片段通道 + 图邻域扩展；两种模式（仅证据 / LLM 生成带引用），支持 SSE 流式输出。
- **证据定位**：任一知识记录可回溯到来源文档版本与字符区间。

### 6. 图谱工作台与治理
- **11 个功能面板**的 SPA 工作台（项目管理、总览、图谱、数据源、脑图、检索问答、知识写入、知识与历史、本体管理、后台任务、快照/评测）。
- **实体治理**：别名、消歧、合并（带审计与撤销）、软删除与恢复、操作历史。
- **快照与回滚**、**P/R/F1 评测**（对 gold 标准答案）。
- **可选 Neo4j 投影**：按项目手动同步，SQLite 仍为权威存储。

### 7. 工程与运维
- 服务层 `knowledge_service/`：FastAPI + SQLite（WAL、外键、事务批量写）。
- **后台任务队列**：单工作线程、持久化回执、30 秒心跳、重启后中断标记；任务日志保留最近 2000 条且**凭据脱敏**。
- Windows 下 FAISS 独立子进程隔离，规避 OpenMP 并发段错误。

## 六、已知边界与风险（诚实项）

- 无身份认证 / 角色权限 / 多级审批，当前为本机审核留痕。
- 后台为**单工作线程**，无批次级恢复与硬性总超时；批量上传为逐文件独立任务。
- Semantica **自动事实时间抽取尚未开启**；跨片关系补抽、递归切片未接入。
- 本体版本升级后，**已有知识不自动迁移**，需另建可审计迁移任务。
- Neo4j 为手动同步副本，切换项目不自动同步。
