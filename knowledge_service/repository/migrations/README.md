# PostgreSQL 迁移

- `baseline_0045.sql` 是截至 0045 的空库结构。默认迁移器在台账为空时以一个事务初始化结构，并登记原来的 45 条迁移及各自的校验和。
- `legacy/` 保存 0001–0045 的原始 SQL。已有数据库继续从台账版本开始执行缺失迁移。旧库依赖这些文件中的数据回填、兼容转换和权限设置。
- 后续变更从 `0046_名称.sql` 开始，放在本目录。已发布的基线和归档 SQL 按只读历史维护，普通变更新增迁移文件。

运行 `python -m knowledge_service.repository.migrate` 应用迁移。用 `--check` 查看版本是否一致，用 `--status` 查看台账和各版本校验和。部署前可在隔离 PostgreSQL 对比空库初始化与完整历史重放，检查表、索引、约束、触发器和应用角色权限，再用旧库备份验证增量升级。
