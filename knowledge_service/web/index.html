知识问答

一次请求同时检索证据并生成答案，不会预先加载图谱。

    添加文档

    标有“必填”的项目不能为空。请先在左侧选择当前项目；正文来源二选一。

    文档发布时间与正文中规则的有效期不同，请勿混填。

    正文来源 二选一，无需重复填写
    填写原文对外发布的时间；不确定可留空。添加时间由系统在上传时自动记录。此处不会设置实体或关系的生效／失效时间。
    用于后续筛选，可填平台、地区、业务或标签；只填写已确认的信息。不需要时留空或填 {}。系统自动记录上传时间、来源等信息；当前模型抽取实体和关系，不会自动补齐这些业务标签。
    解析设置 · 切片与实体融合
    处理流程：逐文件切片 → 按项目本体抽取实体 → 抽取关系 → 消歧融合 → 校验与向量化。以下设置对本批文件共用。
    单位为字符，不是 token。条款模式即使全文未达到上限，也按标题／中文条款分片；条款内数字子列表保留，重叠仅用于超长条款内续片。段落模式优先边界，超长内容按长度切开；保留原文字符位置，不额外拼接标题。预览不调用模型、不写入知识，多文件预览首份文件。
    实体与关系抽取使用 Semantica 和已配置的 LLM；切片由服务层执行。语义切片、自动时间抽取及标题上下文拼接尚未接入。取消下方抽取选项时，仅保存文档和片段并向量化。
    结构化知识批量写入
    适合从已有业务系统导入实体、关系、片段。写入前自动按当前本体校验。
    

    知识与版本
    遵循上方查询范围。纠正同一记录会保留系统历史；规则业务换版请创建新 ID 并填写各自有效期。
    修订记录
    软删除不是物理删除：给该记录及其来源派生知识、关联关系打上删除标记并保留旧版本（可撤销、可查历史）。删除文档会级联标记它派生的实体/关系，并撤回对应断言。
    实体消歧与融合
    Semantica EntityMerger · 仅合并同类型、同本体版本和同业务区间的实体，来源与旧版本完整保留。
    

    项目本体
    类、谓词、属性和 SHACL 一起版本化。保存后新任务直接使用新版本，已有知识保留原本体版本。
    本体源码与版本
    选择历史版本查看；编辑 Turtle 后会另存为新版本，不覆盖当前版本。
