      高级解析设置

      系统会根据模型限额和当前负载决定实际并发。

      逐文件解析 → 切片 → 抽取 → 消歧 → 校验与保存。已构建索引的项目随后增量向量化。

      结构化记录导入（高级）面向 API 或业务系统的 JSON 记录导入，不是批量上传文档。
      • 一次可提交 1–1000 条记录。
      • 支持 document、entity、relation、attribute、chunk 类型。
      • 实体、关系与属性按当前项目本体校验；关系通过记录 ID 引用端点。

      知识台账

      遵循上方查询范围。纠正同一记录会保留系统历史；规则业务换版请创建新 ID 并填写各自有效期。

      软删除不是物理删除：给该记录及其来源派生知识、关联关系打上删除标记并保留旧修订（可撤销、可查历史）。删除文档会级联标记它派生的实体/关系，并撤回对应断言。
