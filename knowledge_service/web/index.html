    知识台账

    遵循上方查询范围。纠正同一记录会保留系统历史；规则业务换版请创建新 ID 并填写各自有效期。

    修订记录

    软删除不是物理删除：给该记录及其来源派生知识、关联关系打上删除标记并保留旧版本（可撤销、可查历史）。删除文档会级联标记它派生的实体/关系，并撤回对应断言。

    实体消歧与融合
    Semantica EntityMerger · 仅合并同类型、同本体版本和同业务区间的实体，来源与旧版本完整保留。
    

    项目本体
    类、谓词、属性和 SHACL 一起版本化。保存后新任务直接使用新版本，已有知识保留原本体版本。
    本体源码与版本
    选择历史版本查看；编辑 Turtle 后会另存为新版本，不覆盖当前版本。

    PROJECT & RUN
    项目与运行
    这里看跑得怎么样：项目设置、运行总览、后台任务、快照与评测。
    它不改具体知识（去「知识台账」）、不改分类（去「本体建模层」）——这两件事不在这一页做。
    

    

    运行总览
    按上方查询范围统计当前项目有多少实体、关系、文档与类型分布；只读，不改任何数据，也不包含项目本身的增删改（那在「项目设置」）。
    

    原文数据源
    这里是源文件的加载与阅读入口：上传本地文档后直接看它被解析出来的正文，不做实体与关系分析（那些去「知识写入」看）。
    

    实体关系脑图
    点击分支展开/折叠，沿所选时间与 metadata 范围遍历；自动限制循环和规模。
    

    后台任务
    这里看解析任务跑到哪一步：任务按顺序逐个执行、状态实时保存；服务异常重启后未完成的任务会自动标记为「已中断」，可在下方重新提交。日志默认折叠，展开后在卡片内滚动。
    

    

    这里做两件事：存档（快照保存当前项目的全部实体与关系，恢复前系统会自动再存一份「恢复前自动备份」，随时可以恢复回来）和打分（用标准答案量化抽取质量）。两者都不改本体结构。
    


    项目快照 · 存档与恢复
    

    保存当前项目的全部实体和关系；恢复时系统会先自动保存当前状态，可随时撤销。实体与关系的每次改动本身也有版本历史，这一层是整项目的存档。
